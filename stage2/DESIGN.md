# Stage 2 설계 — 부피 NEO와 불균일 열전달 (설계만, 실행하지 않음)

> **[목표 변경 2026-09-27]** 최종 목표가 "수술 영상 상대 탄성 추정"에서 아래로 바뀜. 수술 영상 역문제는 이후 응용으로 보류함.
> **"방정식에서 유도한 기저를 trunk에 넣는 구조 주입을, 임의 형상의 포인트 클라우드로 일반화한다 (geometry-general)."**
> 핵심 주장:
> 1. 기저는 포인트 클라우드 위 연산자의 저에너지 부분공간임 (NEO가 예측).
> 2. Galerkin으로 풀면 결과가 기저의 span에만 의존함.
> 3. 계수는 고유값의 함수 g(λ)로 형상 간에 공유됨.
> 4. 모드 결합은 국소 계수로 Yᵀ L Y를 조립해 표현함.
> 5. 라플라시안 기저의 적용 범위는 에너지 동등성 상수로 판별함. 부족한 연산자는 보강·다듬기·미세조정으로 해결함.
>
> 아래 로드맵의 4~6단계(탄성 역문제, 표면 관측, 실데이터)는 보류됨. 탄성은 "라플라시안 기저가 부족한 연산자"의 사례로 다룸 (3단계 A). 다른 물리(반응-확산, 헬름홀츠), 실제 형상, 통일 평가(B·C·D)는 승인 후 진행함.

## 0. 최종 목표와 로드맵 (2026-09-25 방향 조정)

**최종 목표:** 수술 영상에서 **조직의 상대 탄성(강성) 분포를 추정**하는 것.
- 열 문제는 최종 목표가 아니라, 점 기반 연산자·부분공간 기저·잔차 경로·계수장 학습 같은 **구조를 검증하는 단계**로 취급함.
- 열치료(Pennes)는 최종 목표에서 제외함.

| 단계 | 내용 | 이 단계에서 검증하는 것 |
|---|---|---|
| **2단계** (현재) | 부피 포인트 클라우드 기반 연산자와 기저 + **스칼라 계수장 짧은 검증** (스칼라 확산에 숨은 계수 κ(x)) | 부피 연산자 정확도(A1), 부피 NEO(A2), 부분공간에 투영한 계수장 학습 구조(F절) |
| 3단계 | **탄성 순문제**: 비균질 영률 E(x)에서 선형 탄성(정적 또는 준정적) 변위 예측 | 벡터 값 연산자(탄성 강성 행렬)를 같은 인터페이스로 사용, 비압축성 처리 |
| 4단계 | **탄성 역문제, 전체 변위 관측**: 부피 전체의 변위장이 주어졌을 때 E(x) 추정 | 계수장 학습 구조를 탄성으로 확장, 식별성 |
| 5단계 | **표면 관측·힘 미지**: 표면 변위만 관측하고 가한 힘을 모름 → **상대 강성** E(x)/E_ref 추정 | 부분 관측, 스케일 모호성 처리 |
| 6단계 | **팬텀·실데이터**: 탄성 팬텀 실험, 수술 영상(내시경·수술 중 영상의 표면 재구성과 변형 추적) | 실제 노이즈·샘플링·경계조건 |

**2단계 설계에 주는 제약:**
1. 연산자 관련 코드는 스칼라 라플라시안에 묶이지 않게 **"연산자를 입력으로 받는" 인터페이스**로 짬(A4). 3단계에서 탄성 강성 행렬 K(블록 3×3)를 그대로 넣을 수 있어야 함.
2. 계수장 학습(F절)은 Pennes 대신 **스칼라 확산 + 숨은 계수**의 최소 버전으로 축소함. 목적은 "부분공간 투영 연산자 Â = Yᵀ K(θ) Y로 숨은 계수를 복원할 수 있는가"를 싸게 확인하는 것이며, 4·5단계 탄성 역문제의 축소판 역할을 함.

## 1단계에서 넘어오는 사실 (전부 [확인])

- **비용 (곡면 N=4000):**
  - robust pc 라플라시안 + ARPACK 96모드: 1.15 s
  - NEO forward: 23 ms, Rayleigh–Ritz: 0.11 s
  - ε 학습: 60 ms/step (batch 8 형상, RTX 3090)
  - r_p(희소 LU 8회): 0.24 s
- **정확도:** 잔차 입력 ε(r, r_p)으로 τ ≤ 0.03 오차 0.19% (PC-discrete 0.25%).
- **point-cloud 라플라시안:** 무작위 샘플에서 약 −5% 강성 편향. nn=20은 N ≥ 8000에서 붕괴. **robust_laplacian의 point cloud 모드는 곡면 전용**임(접평면에서 국소 2D 삼각분할을 만듦). 부피용 구현은 없음.
- **NEO 저장소 (Adversarr/NEO @ d928c31):**
  - 공개 가중치는 곡면용 2개뿐임(Ours-Large, Ours-Small-NoRoPE).
  - Ours-Large 학습 설정(체크포인트 hparams): batch 112, 400 epoch, 84k step(210 step/epoch → 약 23.5k 샘플/epoch), muon lr 5e-4, 16-mixed, targ_dim 96, 출력 256.
  - `exp/pretrain_datagen/tet_remeshing.py`에 **부피 파이프라인이 이미 있음:**
    1. TetWild 사면체 메쉬를 입력으로 받음.
    2. P1 FEM 강성 K와 consistent 질량 M을 만듦.
    3. `eigsh(K, k=96, M, sigma=1e-8)`로 노이만 고유쌍을 구함.
    4. 부피에서 균일 무작위로 점을 샘플링하고, 고유벡터를 무게중심 보간함.
    5. 점별 질량은 **균일한 V/n**으로 둠.
  - 학습은 `exp/pretrain_tet/train.py`, `g2pt/training/pretrain_tet.py`, `exp/conf/pretrain_tet.yaml`이 담당함. 체크포인트는 공개되지 않았음.
  - 모델 입력은 좌표와 질량뿐임(`get_model(3, 3, ...)`, `model(x, x, mass)`). **경계 플래그 입력은 없음.**
  - `scripts/heat_distance.py`에 NEO 부분공간을 coarse space로 쓰는 **deflated PCG가 구현되어 있음:**
    - `DeflationSpace`: E = YᵀAY, P_D 사영
    - `deflated_pcg`
    - 가법형 2-level 전처리기
    - 기본 전처리기: Jacobi 또는 ilupp ICholT
  - 논문 부록 Algorithm 2 원문은 로컬에 없어서 대조하지 못했음. 아래 D절은 이 코드를 근거로 함.

## A. 부피 NEO

### A1. 부피 포인트 클라우드용 라플라시안·질량 후보

모델에는 연결 정보를 주지 않는다는 1단계 원칙을 유지함. 정답은 사면체 메쉬 FEM으로 만들고, 모델 쪽 연산자는 점만으로 구성함.

| 후보 | 구성 | 장점 | 단점·위험 |
|---|---|---|---|
| (1) 사면체 메쉬 P1 (cotan) | TetGen·gmsh 등으로 만든 메쉬에서 K, lumped M | 수렴성이 확실하고(고유값 O(h²)), 품질 메쉬에서 안정적임. 저장소 `tet_remeshing.py`의 조립 코드를 재사용할 수 있음 [확인] | 연결 정보가 필요하므로 **정답과 학습 타깃 생성 전용**임 |
| (2) 점의 3D Delaunay + **SDF로 바깥 사면체 제거(필수)** → P1 | `scipy.spatial.Delaunay`(3D)는 볼록 껍질 전체를 채움. 오목부(컵 안쪽 등)를 채운 사면체를 그대로 두면 **가짜 열 경로**가 생기므로, 사면체 중심(과 변 중점)에서 SDF > 0(바깥)이면 제거. SDF는 절차적 데이터에서는 해석식, 실제 데이터에서는 표면 점과 법선의 winding number로 계산 | 대칭 PSD이고, 질량 = 부피로 일관적임. 점 외 추가 정보가 거의 필요 없음 | **sliver 사면체**가 생겨 cotan 가중치가 크거나 음수가 되고, 오차와 조건수가 나빠짐. 비볼록 경계를 잘못 자르면 질량이 틀어짐 [추측: 무작위 점에서 sliver 비율이 높을 것] |
| (3) kNN 그래프 라플라시안 (가우시안 커널) | w_ij = exp(−‖xᵢ−xⱼ‖²/4ε), M은 부피/N 또는 kNN 밀도 추정 | 구현이 가장 단순하고 GPU로 옮기기 쉬움 | 편향이 O(ε)이고 경계층에서 O(1)인 오차가 남음. 대역폭에 민감함. 질량 추정과 스케일 보정(아래 c₃) 필수 |
| (4) GMLS / RBF-FD 라플라시안 | 국소 다항식 재생 스텐실 | 고차 정확도, 노이만 경계를 스텐실로 다룰 수 있음 | **비대칭**이라 대칭 고유문제·Rayleigh–Ritz 틀이 깨짐. 안정화(초과샘플링, 대칭화)가 필요함 |
| (5) 절단 Voronoi 유한체적 | 셀 부피 = 질량, 면적/거리 = 가중치 | 가중치가 양수이고 대칭·PSD. 물리적 의미가 명확함 | 표면으로 Voronoi를 절단하는 기하 연산이 무거움. 쓸 만한 라이브러리가 확인되지 않음 [추측] |
| (6) 국소 사면체분할의 합집합 (robust_laplacian의 3D판) | 점마다 kNN 국소 Delaunay 사면체를 만들고 합침 | 곡면에서 검증된 아이디어를 3D로 옮김 | 기존 구현이 없어 직접 구현해야 함. 1단계에서 본 곡면판의 편향 문제가 3D에서도 나타날 수 있음 [추측] |

**SDF 제거 단계 검증 (P1에 포함):**
- 오목 형상(컵, C자 관, 토러스 구멍)에서 제거 전후 ΣM/V를 비교함.
- 떨어진 두 점 사이의 열 전달 시간을 비교함(가짜 경로가 있으면 짧아짐).
- 경계 근처 누락 사면체 비율을 확인함(제거가 과하면 구멍이 생김).

**[결정 필요] 점 기반 연산자:**
- ★ **(2)와 (3)을 먼저 비교하고, 필요하면 (5)를 시험.**
  - (2)는 FEM과 같은 계열이라 1단계 파이프라인(보정 c, r_p, Rayleigh–Ritz)을 그대로 쓸 수 있음.
  - (3)은 가장 튼튼한 대안임.
- (4)와 (6)은 구현 비용이 커서 보류.

**보정 (1단계의 부피판):** 좌표 함수는 |∇xᵢ|² = 1이므로 Σᵢ ∫|∇xᵢ|² = 3V임. 따라서 선형 정밀도 보정 계수는 **c₃ = 3·ΣM / Σᵢ xᵢᵀLxᵢ**이고, 해석해 없이 점만으로 계산할 수 있음. [확인: 곡면판 c = 2ΣM/Σ…가 1단계에서 동작함. 부피판은 [추측]]

**정확도·안정성 확인 계획** (NEO 재학습 전에 수행, CPU만 사용):

1. **해석해가 있는 영역에서 고유값 비교:**
   - 단위 공 노이만: j'_l(k)=0 → λ = k²
   - 단위 공 디리클레: j_l(k)=0
   - 정육면체: π²(a²+b²+c²)
   - 구각
2. **변수:**
   - N ∈ {2k, 4k, 8k, 16k, 32k}
   - 샘플링: 무작위, blue-noise(FPS·Poisson disk), 비균일(밀도 5배)
   - 표면 점 비율
   - 이웃 수와 대역폭
3. **지표:**
   - ΣM/V
   - 저차(i ≤ 10)와 고차(i = 80–95) 편향. c₃ 보정 전후를 비교
   - 음의 비대각 가중치 비율
   - 최소 고유값 ≥ 0 여부
   - 조건수
   - 사면체 FEM 정답 대비 열방정식 해 오차(1단계 PC-discrete의 부피판)
4. **합격 기준 [결정 필요]:**
   - 예: N=8k blue-noise 기준 c₃ 보정 후 |저차 편향| ≤ 1%, ΣM/V ∈ [0.98, 1.02]
   - 무작위 샘플에서 N이 커질 때 붕괴하지 않을 것(1단계 nn=20 사례의 재발 방지)

- NEO 곡면 학습은 체크포인트 step 수로 역산하면 epoch당 약 23.5k 샘플, 형상당 4개 샘플이므로 형상 약 6–7k개로 추정 [추측: README 전처리 명령의 `--per-mesh-count 4`와 split 0.9로 역산].

  - (a) 미세조정: 절차적 부피 형상 약 3k개 × 4 샘플 × 2048점, k=96
  - (b) 처음부터: 약 6k개

**정답 고유쌍 생성 시간 (CPU, 형상당):**

| 단계 | 시간 |
|---|---|
| 사면체화 | 1–5 s [추측] |
| P1 조립 | 1 s 미만 |
| `eigsh k=96`, 사면체 정점 1–3만 | 5–30 s [추측: 3D에서 LU fill이 곡면(4k 정점, 1단계 수 초)보다 훨씬 큼] |

**학습 시간:**
- 저장소 설정 그대로(batch 112, 2048점, fp16)면 step당 0.4–0.8 s로 추정 [추측: 추론 실측 19–23 ms/샘플(fp32, N=2–4k)에서 역전파와 배치 효율로 환산].
  - 84k step: 9–19 GPU-h, DDP로 GPU 3장이면 벽시계 3–7 h [추측]
  - (a) 미세조정은 그 20–40% [추측]
- **첫 단계로 1 h 파일럿을 돌려 step 시간과 수렴 곡선을 실측한 뒤 확정할 것을 권장.**

**저장소 부피 파이프라인을 그대로 쓸 때 주의할 점:**
1. 점별 질량이 균일(V/n)로 고정되어 있음. 무작위 균일 샘플에서만 맞고, blue-noise·비균일·표면점 혼합 샘플에서는 점별 질량(A1 연산자의 lumped M)으로 바꿔야 함.
2. 입력 데이터가 TetWild(Thingi10K) 외부 데이터셋 경로를 가정함. 다운로드 없이 절차적 형상으로 대체하려면 전처리 스크립트를 새로 짜야 함.
3. 경계 플래그 입력이 없음(A3 참고).

### A3. 경계조건

| 경계조건 | 처리 방법 후보 | 비고 |
|---|---|---|
| 노이만 | 지금 그대로 (자연 경계조건) | 부피 FEM과 점 연산자 모두 자동으로 만족 |
| Robin (∂u/∂n + κu = κu_∞) | 연산자에 경계 질량 항 κB를 더함. B는 표면 점의 면적 가중치로, 표면 점만 robust_laplacian 곡면 모드에 넣어 질량을 얻을 수 있음 [추측]. 기저는 **노이만 NEO span에서 (L + κB)로 Rayleigh–Ritz** | κ가 중간 정도면 Robin 고유함수가 매끄러워 span 품질이 유지될 것 [추측]. κ → ∞이면 디리클레에 가까워져 품질이 떨어짐. u_∞ ≠ 0은 u = u_∞ + v로 치환 |
| 디리클레 | (i) ★ **거리함수 곱 기저** ψ_k = d(x)·φ_k (d = 표면까지 거리, 표면 점으로 근사)를 쓰고 L_D로 Rayleigh–Ritz. 동차 디리클레를 span에서 정확히 만족함 (R-function 방식). (ii) 디리클레 고유쌍으로 NEO를 따로 재학습하고 입력에 경계 플래그 채널을 추가(모델 입력 차원 변경 = 코드 수정 + 재학습). (iii) 페널티/Nitsche(큰 κ의 Robin) | (i)은 재학습이 필요 없지만 d의 매끄러움에 정확도가 좌우됨 [추측]. (ii)는 가장 정확할 것이나 비용이 큼. (iii)은 간단하지만 부정확하고 조건수가 나쁨 |
| 비동차 (u = g on ∂Ω) | lifting: u = G + v. G는 조화 확장이나 한 번의 희소 solve로 구하고, v에는 동차 문제를 적용 | r_p 경로는 전체 연산자를 쓰므로 어떤 경계조건이든 바로 적용됨 [확인: r_p = (M + tL_bc)⁻¹M r 구조] |

**[결정 필요] 2단계에서 다룰 경계조건 범위:**
- ★ 노이만과 Robin을 먼저 하고, 디리클레는 (i)로 검증만.
- Pennes(B3)에서 피부 대류는 Robin이 자연스러움.

### A4. 연산자 인터페이스 (3단계 탄성까지 재사용)

2단계 코드는 "스칼라 라플라시안"을 가정하지 않고, **이산 연산자 묶음을 입력으로 받는** 형태로 설계함.

```
Operator:
  K         : (n·d) × (n·d) 희소 대칭 PSD 행렬   # d = 1 (스칼라 확산), d = 3 (선형 탄성)
  M         : (n·d) 대각(lumped) 또는 희소 질량 행렬
  dof_dim   : d
  assemble(theta_e) -> K(θ)       # 요소별 계수(κ_e 또는 E_e, ν_e)로 재조립; 미분 가능 경로 제공
  element_grads : 요소별 기저 기울기 (Gram 형태 YᵀK(θ)Y 계산용)
  constraints   : 경계조건(노이만 없음 / Robin 항 B / 디리클레 고정 자유도), 강체 모드(탄성: 6개)
```

- **소비자 코드**는 이 인터페이스만 사용함: 고유분해·부분공간 기저, Rayleigh–Ritz, 잔차 r과 사전해 r_p, deflated PCG, 계수장 모델(F절).
- **스칼라 구현(2단계):** Delaunay-P1 + SDF 제거. K = Σ_e κ_e vol_e ∇φ_eᵀ∇φ_e.
- **탄성 구현(3단계):** 같은 사면체 분할에서 K = Σ_e B_eᵀ D(E_e, ν_e) B_e vol_e (블록 3×3).
  - 비압축성 locking 대응(위험 요소 8)을 위해 혼합 정식화(변위–압력)나 선택적 감차 적분을 끼울 수 있게, "요소 강성 계산" 부분을 교체 가능한 함수로 둠.
- 부분공간 쪽은 d > 1이면 기저가 (n·d) × m이 되고 강체 모드(평행이동 3 + 회전 3)를 영공간으로 다뤄야 함. 노이만 스칼라 문제의 상수 모드 처리를 일반화한 것임.
- 부피 연산자 검증 코드(`stage2/opcheck.py`)의 조립 함수 `tet_p1(P, T)`는 이 인터페이스의 스칼라 구현 초안에 해당함. 인터페이스 정리는 2단계 본 구현 때 반영함.

## D. r_p 가속 (NEO 부분공간 deflated PCG)

**문제:** A_t x = b, A_t = M + t·L (Robin이면 + tκB), b = M r. τ별로 8회 풀어야 함.
- 1단계에서는 희소 LU를 τ마다 새로 해서 0.24 s/형상(곡면 4k)이 들었음 [확인].
- 3D에서는 LU fill-in이 크게 늘어 N = 1–2만에서 비용이 급증할 것 [추측: 일반적인 3D 희소 직접법의 특성].

**계획** (저장소 `scripts/heat_distance.py`의 `DeflationSpace`/`deflated_pcg`를 기반으로 함 [확인]):

1. **coarse space Y = NEO Ritz 벡터.**
   - Y가 M-정규직교이고 L을 대각화하면(Rayleigh–Ritz 결과이므로) **E = YᵀA_tY = I + tΛ가 대각**이 됨.
   - 따라서 τ가 바뀌어도 coarse 행렬을 다시 분해할 필요가 없음(O(Nk) 적용) [확인: Rayleigh–Ritz 성질에서 바로 나옴].
   - 256차원 전체 span을 쓰면 E = I + t·SᵀLS (256×256 dense)도 저렴함.
2. **초기값:** x₀ = r. t → 0이면 x₀가 정확해가 되고, 1단계 (b)에서 작은 τ의 r_p ≈ r이었음 [확인]. 또는 직전 τ의 해를 씀(τ가 증가하는 순서).
3. **기본 전처리기 후보:**
   - Jacobi(diag A_t)
   - pyamg SA-AMG: neo 환경에 pyamg 5.3.0 설치되어 있음 [확인]
   - ilupp ICholT: 저장소가 사용하지만 **neo 환경에 없음** [확인]
   - 가법형 2-level(`_make_two_level_preconditioner`)과 사영형 deflation을 비교함.
4. **정밀도:** r_p는 ε의 입력 특징이므로 완전 수렴이 필요 없을 수 있음. tol ∈ {1e-2, 1e-3, 1e-4, 1e-6}별로 **최종 모델 오차**가 얼마나 민감한지 재서 결정함 [추측: 1e-3–1e-4면 충분할 것].
5. **예상 효과** [추측]:
   - κ(A_t) ≈ (m_max/m_min)·(1 + tλ_max)/(1 + tλ_min)
   - 작은 τ: tλ_max가 작아 Jacobi-PCG만으로도 수 회에서 수십 회 반복이면 됨.
   - 큰 τ: deflation이 λ₉₇ 아래 모드를 제거하므로 유효 조건수가 대략 (1 + tλ_max)/(1 + tλ₉₇)로 줄어듦. 반복 수는 λ₉₇/λ₁ 비율의 제곱근 정도로 줄어들 것.
   - N이 클수록 LU 대비 이득이 커짐. 행렬-벡터 곱은 torch sparse CSR로 GPU에 올릴 수 있음.
6. **측정 계획:**
   - N ∈ {4k 곡면, 1만/2만/5만 부피}, τ 8개, IC 4개(블록)에 대해 비교: LU, Jacobi-PCG, AMG-PCG, deflated(Y96, Y256) × {Jacobi, AMG}
   - 지표: 반복 수, 시간, 최종 모델 오차 변화
   - 1단계 곡면 데이터로 먼저 검증할 수 있음(CPU만 사용, 짧음).

## F. 숨은 계수장 학습 — 스칼라 확산 최소 버전 (2026-09-25 축소)

**범위 (축소):** Pennes(B3)는 하지 않음. **u_t = ∇·(κ(x)∇u)**(노이만, 관류·열원 없음)에서 모델에 주지 않는 κ(x)를 부분공간 투영 연산자로 복원할 수 있는지만 확인함.
- κ(x)는 결정 6에 따라 표면 거리 기반 층 구조(형상 크기에 비례한 고정 경계, 고정 값)로 둠.
- 이 실험은 4·5단계 **탄성 역문제의 축소판**임: "관측(해)만으로 학습해서, 투영된 연산자 Yᵀ K(θ) Y의 계수 θ를 복원" 구조가 같고, 스칼라라서 싸게 돌릴 수 있음.
- 아래 식에서 w(x)(관류) 항은 이번 범위에서 0으로 둠. 탄성으로 가면 K(θ)가 탄성 강성 행렬로 바뀜(A4).


**문제:** 1단계 g_θ는 모드마다 독립적인 감쇠율만 주는 **대각** 연산임.
- 균일 계수에서는 고유함수가 서로 섞이지 않으므로 충분했음. 1단계에서 스케일 c를 찾아낸 것이 그 예임.
- κ(x)나 w(x)가 위치마다 다르면 A = L_κ + M·diag(w)를 균일 라플라시안 고유기저 Y로 표현한 YᵀAY가 **비대각**이 됨(모드 간 결합). 대각 구조로는 원리상 표현할 수 없음.
- **따라서 1단계 구조를 B2와 B3에 그대로 쓰면 안 됨.**

**제안 (사용자 의견 반영): 해 대신 숨은 계수장을 학습함.**

$$\kappa_\theta(x),\ w_\theta(x) = \mathrm{NN}(F(x), x, d(x)) \quad (\text{양수성: softplus 또는 log-공간})$$

$$\hat A = Y^\top\big(L_{\kappa_\theta} + M\,\mathrm{diag}(w_\theta)\big)Y, \qquad c(t) = e^{-t\hat A} c_0,\quad c_0 = Y^\top M u_0$$

$$\hat u(t) = Y c(t)\ +\ [\text{모드 밖 잔차 경로 } r_p,\ \epsilon_\theta]$$

**장점:**
1. 함수공간의 연산자를 부분공간에 투영한 것이므로 span 안에서 기저를 어떻게 고르든 결과가 같음(회전·부호 불변). [확인: Galerkin 사영의 성질]
2. m × m 행렬 지수(m = 96 또는 256)라 계산이 쌈. Â가 대칭이면 `eigh`로 미분 가능한 exp를 계산할 수 있음.
3. 학습된 κ̂, ŵ를 정답 계수장과 직접 비교할 수 있어 해석이 가능함. "숨은 조직 특성을 복원했다"는 형태의 결과가 됨.
4. 1단계에서 g_θ가 c를 찾은 것의 일반화임(κ ≡ 상수면 같은 구조로 돌아감).

**구현 세부 (설계):**
- **미분 가능한 조립:** Delaunay-P1(SDF 제거 후)에서 사면체마다 κ_e를 꼭짓점 κ̂의 평균으로 둠.
  - YᵀL_κY = Σ_e κ_e·vol_e·(∇Y_e)ᵀ(∇Y_e)이고, ∇Y_e(사면체별 상수, 3 × m)를 미리 계산해 두면 **가중 Gram 1회**로 끝남.
  - 비용은 사면체 수 × 3 × m²이며, 사면체 6만 개와 m = 96이면 형상당 약 1.7 GFLOP [추측: GPU에서 1 ms대].
  - 질량항은 Yᵀdiag(m ⊙ w)Y임.
- ~~Pennes 선형 열원~~: 범위에서 제외함(2026-09-25). 참고로 상수 열원 q가 있으면 c(t) = e^{−tÂ}c₀ + Â⁻¹(I − e^{−tÂ})q로 닫힌 형태가 있음.
- **기저 차원:** 균일 라플라시안 기저가 불균일 연산자의 저차 고유공간을 얼마나 담는지가 정확도를 좌우함. 계수가 매끄러우면 대부분 담기겠지만 [추측] 층 경계가 날카로우면 부족할 수 있음. → NEO span 256차원 전체를 m으로 쓰는 선택지를 둠.
- **잔차 경로:** r = u₀ − YYᵀMu₀는 그대로 씀. r_p는 두 가지 선택지가 있음(아래 결정 9):
  - (i) 균일 L로 만든 고정 특징으로 두고, 오차는 ε가 보정
  - (ii) 예측한 L_κ̂로 (M + tL_κ̂)⁻¹Mr을 풀고 adjoint로 미분(같은 행렬로 한 번 더 solve). D절의 deflated PCG가 여기서도 유용함.
- **학습 신호와 평가:** 손실은 해의 오차만 씀. 계수장은 평가(해석 가능성)에만 사용함.
  - 평가 지표: 정답 κ, w 대비 상대 L2와 층 경계 위치 오차.
  - 해가 계수에 둔감한 영역(기울기 |∇u|가 작은 곳)에서는 계수가 원래 식별되지 않으므로, **민감도 가중 오차**를 같이 보고함.
- **식별성과 정규화:** κ는 공간적 재분배에, w는 전체 감쇠에 주로 영향을 주므로 대체로 분리될 것 [추측]. 매끄러움이나 TV 사전분포를 가볍게 넣음. 초기값은 κ ≡ c₃, w ≡ 0.
- **대조 실험:**
  - 1단계 대각 g_θ 구조를 B2(최소판)에 그대로 적용 → 모드 결합을 무시하면 얼마나 나쁜지 보여줌
  - 정답 계수로 조립한 Â(oracle-coefficient)
  - 계수장 학습 모델
  - (+ r_p, ε)

**문헌:** 미분 가능한 솔버(adjoint)로 PDE 계수를 추정하는 것은 PDE 제약 최적화와 역문제 분야에 선행 연구가 많음. 신경망으로 계수장을 매개화하는 연구도 있는 것으로 앎. **구체적인 선행 연구 목록과 차별점은 문헌조사로 확정해야 함** — 이 문서에서는 특정 논문을 인용하지 않음.

**위험 요소 (영향이 큰 순):**
1. **점 기반 부피 라플라시안의 정확도·안정성 (A1).** 1단계 곡면에서도 샘플링 불규칙성으로 −5% 편향과 붕괴가 있었음. 3D는 sliver와 경계층 때문에 더 나쁠 수 있음 [추측]. → P1에서 합격 기준을 통과하지 못하면 뒤 단계를 조정해야 함(예: 입력을 blue-noise 샘플로 제한하거나 연산자 (5)로 전환).
2. **NEO 부피 재학습 비용과 수렴.** 공개 체크포인트가 없고 추정 GPU 시간의 폭이 큼. → 파일럿으로 확정. 미세조정으로 위험을 줄임.
3. **숨은 계수 설정(B2)의 적절성.** 계수가 관측 가능한 입력으로 결정되지 않으면 줄일 수 없는 오차가 생김 → 층 구조 규칙으로 설계.
4. **경계(표면) 점 식별.** 절차적 데이터에서는 샘플러가 알려주지만, 실제 스캔 데이터에서는 추정해야 함(Robin, 디리클레, 거리함수 d에 필요).
5. **메모리와 디스크** [추측]:
   - N이 1–2만이면 ε trunk 텐서가 약 3–5배 커져 batch를 줄여야 할 수 있음(1단계 peak 8 GB → 20 GB 초과 가능).
   - 디스크: 1단계가 600형상 × 4k점에 4.2 GB였음 [확인]. 2단계(NEO 데이터 3–6k형상 × 4 × 2048 × 96, 열 데이터 약 1k형상 × 1–2만점)는 30–60 GB로 예상. 현재 여유는 116 GB [확인, 1단계 시작 시점].
6. **도구와 라이선스:** pygalmesh는 빌드 위험이 있음. TetGen은 AGPL [추측: 연구용으로 문제없을 것].
7. **공유 서버 자원:** 다른 사용자 작업이 올라오면 CPU·GPU 수를 줄여야 하고 일정이 늘어남.

**탄성 단계(3–5단계)의 난제 (방향 조정으로 추가):**

8. **비압축성 locking.** 연조직은 거의 비압축성(푸아송비 ν ≈ 0.45–0.499)이라, P1 사면체 변위 요소는 체적 locking을 일으켜 강성을 과대평가하고 변위를 과소평가함.
   - 대응 후보: 변위–압력 혼합 정식화(예: P2–P1, 안정화 P1–P1), 선택적 감차 적분, 또는 ν를 약간 낮춘 근사.
   - A4 인터페이스에서 요소 강성 계산을 교체 가능하게 두는 이유임.
   - 점 기반 Delaunay 분할은 sliver가 있어 locking과 겹치면 더 나빠질 수 있음 [추측].
9. **표면만 관측 가능.** 수술 영상에서는 내부 변위를 볼 수 없고 표면 변형만 재구성됨. 내부 강성은 표면 데이터로 약하게만 결정됨(깊은 곳일수록 식별성이 낮음).
   - 4단계(전체 변위)에서 식별성을 먼저 확인하고, 5단계에서 표면 관측으로 줄였을 때 복원 가능한 깊이와 해상도를 정량화해야 함.
   - 사전분포(매끄러움, 조직 구조)의 역할이 커짐.
10. **힘을 모르는 데서 오는 스케일 모호성.** 가한 힘(견인력)을 모르면 E(x)와 힘을 같은 배율로 곱해도 변위가 같음. 따라서 **상대 강성 E(x)/E_ref만 추정 가능**함.
    - 모델 출력과 평가 지표를 처음부터 스케일 불변(예: 정규화한 로그 강성, 기준 영역 대비 비)으로 정의해야 함.
    - 2단계 스칼라 실험에서도 같은 성질(κ 전체 배율과 시간 배율의 교환)이 있으므로, 계수 복원 평가를 상대값 기준으로 함께 보고함.

## 결정 기록 (사용자 답변 반영, 2026-09-25)

1. **부피 연산자:** Delaunay-P1 + SDF 바깥 제거를 기본으로 하고, kNN 그래프 라플라시안과 비교함.
2. **통과 기준:** 제안 기준(c₃ 보정 후 |저차 편향| ≤ 1%, ΣM/V ∈ [0.98, 1.02])에 두 가지를 추가함.
   - (i) 세밀한 사면체 FEM 대비 **첫 32모드 span loss ≤ 1e-3** (고유벡터 기준)
   - (ii) 무작위 샘플에서 N이 커질 때 고유값·span 오차가 **단조 감소하는지(수렴)** 확인. 1단계 곡면 nn=20에서 N을 늘리자 −39%까지 나빠진 사례를 반복하지 않기 위함.
3. **NEO 재학습:** 미세조정과 처음부터 학습을 1시간 파일럿으로 비교함. 파일럿은 모델 구조를 바꾸지 않음. 경계 여부 입력 채널 추가는 파일럿 결과를 보고 판단함.
4. **경계조건:** 노이만과 Robin. 피부 대류는 Robin, 동맥 혈액 온도는 Pennes 항으로 처리함.
5. **문제 설정:** B1 → B3 + B2.
6. **숨은 계수 규칙:** 표면 거리 기반 층 구조.
   - 층 경계 거리는 형상 크기(예: 등가 반지름)에 비례한 **고정 비율**로 두고, 계수 값도 **고정**함.
   - 형상마다 무작위 두께를 쓰는 설정은 이번 단계에서 제외함(모델이 알 수 없어 문제가 성립하지 않음).
   - 이후 확장: 형상별 두께를 스칼라 입력으로 주는 방식(환자 정보 입력과 비슷).
7. **사면체 메쉬 도구:** tetgen + gmsh, 예비로 wildmeshing. `neo` 환경 안에만 설치함.
   - **라이선스:** TetGen은 **AGPL-3.0**, gmsh는 **GPL-2.0 이상**. 연구용으로는 문제없지만, 코드를 공개할 때 이 도구에 링크하거나 재배포하는 부분의 라이선스를 검토해야 함. fTetWild(wildmeshing)는 MPL-2.0으로 앎 — 공개 전 확인 필요.
8. **P0:** 먼저 진행. CPU 부분은 바로 시작하고, GPU 부분은 DON 탐색이 끝난 뒤에 함.
9. **계수장 모델 세부:**
   - (a) **m = 256.** 직교화할 때 rank-revealing 단계를 넣음(M-가중 SVD 또는 pivoted QR로 작은 특이값을 잘라냄). 유지된 차원 수를 형상별로 보고함. 97번 이후 NEO 출력은 학습되지 않은 영역이라 거의 선형 종속인 벡터가 섞일 수 있기 때문.
   - (b) r_p는 균일 L로 만든 **고정 특징**. 부족하면 adjoint 방식을 고려함.
   - (c) 계수 네트워크 입력은 **[F, x, d(x)]와 [F, x] 두 가지 모두** 실험함. d를 주면 계수가 정확히 d의 함수라 복원이 지나치게 쉬움. [F, x]로도 계수를 추론하는지 보여야 함.
   - (d) 대각 g_θ 대조 실험 포함.

**진행 순서:** DON 탐색 완료 → P0 → 부피 연산자 검증(결정 1, 2) → NEO 파일럿(결정 3).
**F절(계수장 학습) 구현**은 문헌조사로 역문제 분야 선행 연구와의 위치를 확인한 뒤 시작함.

- **연산자 코드:** "연산자를 입력으로 받는" 인터페이스로 설계함(A4). 3단계에서 탄성 강성 행렬을 그대로 넣을 수 있게 하기 위함.
- **F절:** B3(Pennes) 대신 **스칼라 확산 + 숨은 계수** 최소 버전으로 축소함.
- **위험 요소:** 탄성 단계 난제(locking, 표면만 관측, 힘 미지로 인한 스케일 모호성) 추가(E절 8–10).
- **부피 연산자 검증:** 입구가 열린 오목 형상(컵)을 추가함. 구형 껍질(닫힌 공동)과 토러스(구멍)에 더해, SDF 제거가 **입구가 열린 오목부**에서도 동작하는지 확인하기 위함.

## 부피 연산자 검증 결과 반영 (2026-09-25, `REPORT_opcheck.md`)
