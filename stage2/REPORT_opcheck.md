# 2단계 부피 연산자 검증 (결정 1·2)

**결론:** **Delaunay-P1 + SDF 바깥 제거 + 경계 sliver 제거**가 5개 영역 모두에서 통과 기준을 만족함.
- 기준 (1): N=8k 준균일 샘플.
- 기준 (2): 무작위 샘플에서도 N이 커질수록 오차가 단조 감소(수렴).
- kNN 그래프 라플라시안은 모든 경우 불합격.
- SDF 제거는 오목 영역에서 필수임.

재현 (CPU만 사용, `neo` 환경):

```bash
python stage2/opcheck.py
python stage2/opcheck.py --cup
python stage2/report_opcheck.py
```

- 약 9분 (본 실행 420건 + 컵 120건, 프로세스 20개)
- 결과: `results_opcheck/`의 `summary.csv`, `verdicts.csv`, `tables.md`, `fig_opcheck.png`
- 이전 버전 결과: `v1_no_sliver_filter/`, `v2_allsurface_filter/`

## 설정

| 영역 | 오목성 | 기준 (노이만) |
|---|---|---|
| ball (단위 공) | 볼록 | 해석해: j_l′(k) = 0, 고유함수 j_l(kr)·Y_lm |
| cube ([−½, ½]³) | 볼록, 평면 면·모서리 | 해석해: π²(a²+b²+c²), 코사인 곱 |
| shell (0.5 ≤ r ≤ 1) | **닫힌 공동** | 해석해: j_l′(ka)y_l′(kb) − j_l′(kb)y_l′(ka) = 0 |
| torus (R=0.7, r=0.3) | **구멍 (genus 1)** | 세밀 gmsh 사면체 P1 FEM (3.9만 정점, h=0.04 대비 차이 0.18%), 고유값만 |
| **cup** (원기둥 r=1에서 r=0.65·깊이 0.7 공동 제거, 위가 열림) | **입구가 열린 오목부** | 세밀 gmsh 사면체 P1 FEM (7.1만 정점, h=0.04 대비 차이 0.09%), 고유값만 |

**점 샘플링** (표면 점 수는 내부 간격에 맞춤):
- **무작위:** 부피 안 iid + 표면 iid.
- **준균일:** 내부는 지터 격자(경계에서 0.35h 이상 떨어뜨림), 표면은 FPS.
- N ∈ {2k, 4k, 8k, 16k, 32k}, seed 3개.

**연산자** (모두 선형 정밀도 보정 c₃ = 3ΣM / Σᵢ xᵢᵀLxᵢ 적용):

| 연산자 | 구성 |
|---|---|
| delaunay | 3D Delaunay → **SDF 제거**(사면체 중심 SDF < 0 또는 변 중점 SDF < −h/4) → **경계 sliver 제거**(표면 꼭짓점 ≥ 3개이면서 품질 vol/l_max³ < 1e-3) → P1 강성 + lumped 질량 |
| delaunay_nocarve | SDF 제거만 뺀 것 (오목 영역만) |
| knn16 / knn32 | 자기조정 가우시안 가중치 그래프 라플라시안, 질량 = kNN 구 부피 / k |

- P1 FEM은 선형 함수를 정확히 재현하므로 delaunay에서는 c₃ = 1이 자동으로 나옴.

**지표:**
- ΣM/V (질량비)
- 저차 편향: i = 1..10 평균, 부호 있음
- 평균 |고유값 상대오차|: i < K_ref
- span loss: 첫 K_ref개 기준 모드. K_ref는 32 이하에서 가장 큰 완전한 축퇴군 개수로 ball·cube 29, shell 26. 32에서 자르면 축퇴군이 중간에 잘려 손실이 인위적으로 커지기 때문임.

## torus·cup 고유벡터 비교 (보완, `opcheck_span_fem.py`)

**방법:**
- 기준: 세밀 gmsh 사면체 메쉬(h=0.03: torus 39,348 정점, cup 70,704 정점)의 P1 고유벡터 48개.
- 점 위치로 옮기는 방법: 가까운 사면체 중심 16개를 후보로 사면체 위치를 찾고 무게중심 보간함.
  - 곡면 표면 위의 점은 다면체 메쉬보다 살짝 바깥에 있어서 가중치를 잘라서 처리함(torus 점의 30%, cup 17%). 차이는 h²/8R 수준.
- 기준해 자체의 오차: h=0.04 기준해와 h=0.03 기준해 사이의 span loss가 torus 2.2e-5, cup 1.3e-5로 아래 결과보다 충분히 작음.
- 샘플과 seed는 `opcheck.py`와 같음(3개 평균).

| span loss | N=2k | 4k | 8k | 16k | 32k |
|---|---|---|---|---|---|
| torus delaunay 준균일 | 4.2e-3 | 9.7e-4 | **2.3e-4** | 6.8e-5 | 2.1e-5 |
| torus delaunay 무작위 | 2.1e-2 | 2.7e-3 | 7.1e-4 | 1.8e-4 | 5.6e-5 |
| cup delaunay 준균일 | 5.5e-3 | 1.3e-3 | **3.6e-4** | 1.1e-4 | 3.8e-5 |
| cup delaunay 무작위 | 1.7e-2 | 4.1e-3 | 1.1e-3 | 2.6e-4 | 7.6e-5 |
| torus delaunay_nocarve 준균일 | 1.6e-1 | 1.1e-1 | 3.8e-2 | 9.2e-3 | 4.4e-4 |
| cup delaunay_nocarve 준균일 | 2.0e-1 | 2.0e-1 | **1.8e-1** | 1.7e-1 | **1.6e-1** |

**결과:**
- torus·cup 모두 N=8k 준균일에서 span loss ≤ 1e-3을 만족함(2.3e-4, 3.6e-4). 무작위 샘플에서도 단조 감소함.
- 무작위 cup은 8k에서 1.1e-3으로 기준을 살짝 넘고 16k부터 만족함.
- **열린 오목부(cup)에서 SDF 제거를 빼면 고유벡터가 크게 틀리고(span loss 0.16–0.20) N을 늘려도 거의 줄지 않음.** 고유값만 볼 때보다 SDF 제거의 필요성이 더 분명하게 드러남.
- torus에서 SDF 제거 없는 변형이 N이 커질수록 좋아지는 것은 발견한 점 2의 보조 관찰(sliver 필터가 구멍을 채운 사면체 일부를 지움)과 같은 현상임.

## 발견한 점

1. **곡면 point-cloud 라플라시안과 달리, Delaunay-P1은 무작위 샘플에서도 수렴함.**
   - 1단계 곡면(robust_laplacian)에서는 무작위 샘플에서 −5% 편향이 N과 무관하게 남았고, nn=20에서는 N이 커질수록 −39%까지 나빠졌음.
   - 부피 Delaunay-P1은 무작위 샘플에서 편향이 N=32k에서 0.2% 이하로 줄고 span loss도 단조 감소함.
   - P0에서 "무작위 샘플에서는 입력 연산자 편향이 오차 하한"이라고 했던 문제가 부피에서는 이 연산자로 해결될 가능성이 큼.
2. **SDF 제거는 오목 영역에서 필수임.** 사용자가 지적한 가짜 열 경로가 수치로 확인됨.
   - SDF 제거 없이(sliver 필터도 없는 v1 기준) shell +14%, torus +57%, 질량 +14–33%였고 N을 늘려도 줄지 않았음.
   - 입구가 열린 컵에서도 SDF 제거 없는 변형은 N=8k에서 편향 +23%, 질량 +34%임.
   - 보조 관찰: sliver 필터를 넣은 뒤에는 SDF 제거 없는 변형도 N이 커질수록 좋아짐(shell 준균일 32k 질량 1.006). 표면 점만으로 둘러싸인 공동을 채운 사면체들이 N이 크면 납작해져서 sliver 필터에 걸리기 때문으로 보임. 하지만 **컵(열린 오목부)은 32k에서도 질량 +21–25%, 편향 +3–7%**가 남으므로 SDF 제거를 대신할 수 없음.
3. **경계 sliver 제거가 추가로 필요했음 (검증 중 발견, 설계 변경).**
   - 처음 버전(v1)은 cube에서 span loss 0.07–0.13이 N을 늘려도 줄지 않았고, torus 편향이 +2–6%였음.
   - 원인은 경계에 납작하게 붙은 부피 ≈ 0 사면체임. 평면 면 위 표면 점 4개, 또는 표면 점 3개와 면에 거의 붙은 무작위 내부 점 1개로 만들어짐. 역행렬에 가까운 기울기 때문에 강성이 폭주함.
   - v2(네 점 모두 표면인 사면체만 제거)는 준균일 cube와 torus를 고쳤지만, 무작위 cube에서는 span loss가 1.5e-3에서 정체됨.
   - v3(**표면 꼭짓점 ≥ 3개**, 품질 < 1e-3)에서 모두 해결됨. 제거 비율은 사면체의 0.2–1%(ball·shell·cube), 2.6%(torus), 8.7%(cup).
   - 임계값 1e-2는 과해서 고립점이 생겼음(무작위 cube 32k에서 2개).
   - 이 필터는 **어느 점이 표면 점인지 안다고 가정함.** 절차적 데이터에서는 샘플러가 알려주지만, 실데이터에서는 표면 재구성으로 표시해야 함(DESIGN.md 위험 요소 4와 같은 문제).
4. **kNN 그래프 라플라시안은 대안이 되지 못함.**
   - c₃ 보정 후에도 저차 편향이 −4 ~ −17%로 남음.
   - kNN 부피 추정 질량이 20–90% 과대하고, 무작위 샘플에서 더 나쁨.
   - 대역폭이나 질량 추정을 다듬을 여지는 있지만, Delaunay-P1과의 격차(1–2 자릿수)가 커서 더 탐색하지 않음.
5. **비용:** Delaunay-P1 조립 + 고유분해(k=37)가 N=8k에서 약 4–5 s, 32k에서 약 70–100 s(단일 스레드).
   - 대부분 shift-invert LU 시간임. 3D에서는 fill-in이 커서 N에 대해 초선형으로 늘어남. DESIGN.md D절(deflated PCG)의 필요성과 일치함.
   - 결정 2의 "세밀 사면체 FEM 대비 span loss"는 ball·cube·shell은 해석해로, torus·cup은 세밀 gmsh FEM 고유벡터 보간으로 확인함.

## 2단계에 주는 함의

- **A1 결정 확정:** 점 기반 부피 연산자는 **Delaunay-P1 + SDF 제거 + 경계 sliver 제거**로 함. 이 구성이 A4 인터페이스의 스칼라 구현이 됨(`opcheck.py`의 `op_delaunay`, `tet_p1`).
- **샘플 수:** NEO 부피 데이터와 2단계 열 데이터는 **N ≥ 8k**(무작위 샘플 포함)를 권장함. 준균일이면 4k도 기준을 만족함.
- **다음 단계:** NEO 파일럿(결정 3)의 정답 고유쌍을 사면체 FEM으로 만들되, 모델 쪽 입력 질량과 Rayleigh–Ritz 연산자는 이 Delaunay-P1을 씀.
- **남은 확인 [추측]:** 3단계 탄성에서는 같은 Delaunay 분할의 sliver가 체적 locking과 겹쳐 더 민감할 수 있음. sliver 필터 기준을 탄성 강성에서 다시 점검해야 함.
