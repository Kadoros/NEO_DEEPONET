  - t2048: GPU 1, 2048점 정답, 배치 64, 41,299스텝, 0.66초/스텝.

### 결론
1. **4096점 정답이 모든 테스트 세트에서 낫습니다.** GPU 시간이 같은 2048점 정답보다 in-family에서 약 1.5~1.9배, c_tube에서 약 1.2~1.5배 좋습니다. 2048점 정답의 이산화 오차가 학습의 한계가 된다는 앞선 판단과 맞습니다.
2. **학습에서 뺀 형상군(c_tube)에 대한 일반화는 거의 늘지 않았습니다.**
   - 8시간 학습한 t4096도 1시간 파일럿보다 c_tube에서 겨우 약 15% 좋습니다 (1.19e-3 vs 1.39e-3).
   - t2048은 오히려 파일럿보다 나쁩니다 (1.80e-3).
   - 반면 in-family는 파일럿보다 3배 이상 좋아졌습니다. 오래 학습할수록 학습 형상군에 맞춰지는 경향이 있습니다.
   - 새 형상 일반화가 목표라면, 학습을 더 늘리기보다 형상 다양성을 넓히는 것이 우선입니다.
3. 새 형상군 두 개는 학습에 넣자 바로 다른 형상군 수준(5~7e-4)이 됐습니다.

## Branch B: 숨은 κ(열전도도) 복원

### 문제
- 부피 확산 방정식에서 κ = 5인 구형 덩어리 1~3개(반지름 0.15~0.25)를 넣고, 바깥은 κ = 1입니다. 모델에는 κ를 알려주지 않습니다.
- N=8192, Delaunay-P1, ARPACK으로 구한 균질 고유벡터 128개(Y)를 씁니다.
- 관측: 초기조건 8개 × 시점 6개의 내부 전체 온도장.
- 모델: Â = Yᵀ K(κ̂) Y, c(t) = exp(−tÂ) c0, 투영된 관측과의 오차 + H1 평활화.
- 덩어리 찾기 지표:
  - 문턱은 정답을 쓰지 않습니다. 배경(질량가중 중앙값)과 상위 1% 값의 중간입니다.
  - 문턱을 넘는 연결 성분의 중심이 정답 반지름 안에 들어오면 "찾음"으로 셉니다.

### 판정: 256차원 기저가 세기 오차를 줄이는가

- **arpack256: 아니오 / 부분적**. 두 테스트 모두에서 같은 형상 기준으로 내부 평균 오차와 값 오차가 모두 줄지는 않았습니다 (위 표 참고).
