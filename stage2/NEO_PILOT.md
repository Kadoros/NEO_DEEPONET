# 부피 NEO 파일럿 (결정 3) — 표면 가중치 미세조정 vs 처음부터 학습

**결론:** 같은 GPU 1시간 조건에서 **표면 Ours-Large에서 미세조정한 쪽이 처음부터 학습보다 모든 테스트 조건에서 좋음.**
- 같은 형상군 테스트에서 span loss가 1.6–2배 낮고, 학습에 없는 형상군(C자 관)에서는 2–3.5배 낮음.
- 미세조정 학습률 1e-4와 3e-4의 차이는 작음.
- 표면 가중치를 부피에 그대로 쓰면(미세조정 없음) span loss가 미세조정보다 약 3배 높음.

## 재현

```bash
python stage2/neo_vol_data.py                                                          # CPU 20, 23분, 9.8 GB
CUDA_VISIBLE_DEVICES=0 python stage2/pilot_train.py --run ft_lr1e-4 --init large --lr 1e-4        # 각 1시간
CUDA_VISIBLE_DEVICES=1 python stage2/pilot_train.py --run ft_lr3e-4 --init large --lr 3e-4
CUDA_VISIBLE_DEVICES=2 python stage2/pilot_train.py --run scratch_lr5e-4 --init scratch --lr 5e-4
CUDA_VISIBLE_DEVICES=0 python stage2/pilot_eval.py                                     # 약 5분
python stage2/neo_vol_crosscheck.py                                                    # CPU 12개, 세밀 FEM 교차 확인, 약 73분
```

결과물 (`pilot/`):
- `eval.csv`, `tables.md`
- 실행별 `metrics.csv`, `best.ckpt`, `cfg.yaml`
- `data_neo/crosscheck.csv`

## 설정

**데이터** (`neo_vol_data.py`):

| 분할 | 형상 | 샘플 |
|---|---|---|
| 학습 | 5개 형상군 × 500 = 2,500개: SH 섭동 공, superellipsoid solid, 토러스(r/R 0.25–0.55), **열린 컵**, **어긋난 공동 shell** | 형상당 4개(준균일 2 + 무작위 2) × 2048점 = 10,000 샘플 (9,000 학습 / 1,000 검증) |
| 같은 형상군 테스트 | 5개 형상군 × 20 = 100개 | 준균일·무작위 × N=2048·8192 |
| **학습에 없는 형상군 테스트** | **C자로 굽은 관**(200–320° 휘어짐, 둥근 끝) 60개 | 같음 |

- **점:** 준균일은 내부 지터 격자 + 표면 FPS, 무작위는 내부 iid + 면적 균일 표면. 표면 점 수는 내부 간격에 맞춤. 각 형상은 무작위 회전.
- **연산자와 정답:** 검증된 **Delaunay-P1 + SDF 제거 + 경계 sliver 제거**(`volop.py`, REPORT_opcheck.md)를 NEO 정규화 좌표(중심 이동, 최대 좌표 1)에서 직접 만듦. 그 고유벡터 96개(M-정규직교)를 정답으로 씀.
- **NEO 입력 질량:** 같은 연산자의 **lumped 질량**. 저장소 `tet_remeshing.py`의 균일 V/n은 쓰지 않음.
- **저장 형식:** 저장소 `pretrain_tet` h5 형식. 불러올 때 `normalize_pc`가 점에만 적용되므로, 점은 처음부터 정규화 좌표로 저장해 질량·고유벡터 스케일이 어긋나지 않게 함.

**학습** (`pilot_train.py`):
- 저장소 `PretrainTetTraining`(NEO 모델과 손실 그대로: projectfrob + selfdistance)을 사용함. 구조와 최적화 설정은 Ours-Large 체크포인트의 것(transolver, d_model 256, 6층, RoPE, 출력 256, muon + onecycle)임.
- fp16 mixed precision, batch 64. 저장소 기본값 112는 GPU 메모리를 88% 써서 20% 여유 규칙을 어기므로 사용하지 않음.
- `max_time` = 1시간(GPU 1장), 측정한 step 시간으로 스케줄 길이(46 epoch ≈ 6,440 step)를 맞춤.

| 실행 | GPU | 초기화 | max_lr | 도달 epoch / step | 검증 손실 best | 마지막 5 epoch 개선 |
|---|---|---|---|---|---|---|
| ft_lr1e-4 | 0 | Ours-Large (399 텐서, strict) | 1e-4 | 41 / 5,600 | 0.423 | 0.3% |
| ft_lr3e-4 | 1 | Ours-Large | 3e-4 | 39 / 5,383 | **0.396** | 0.8% |
| scratch_lr5e-4 | 2 | 무작위 | 5e-4 (저장소 Large 기본) | 40 / 5,547 | 0.690 | 1.8% (수렴 전) |

- 세 실행 모두 1시간 상한에 걸려 계획한 46 epoch의 85–89%에서 멈춤(실제 step 시간이 측정치보다 약 10% 김).
- 멈출 때의 학습률은 이미 스케줄 끝 구간(5e-6–2.9e-5)이었으므로 미세조정 쪽 영향은 작음. 처음부터 학습은 아직 개선 중이었음.

**평가** (`pilot_eval.py`, 테스트 샘플마다):
- **span loss:** 1 − ‖QᵀMU₉₆‖²/96. Q는 모델 256차원 span을 M-정규직교화한 것(Rayleigh–Ritz 고유벡터), U₉₆은 정답 Delaunay-P1 고유벡터.
- **Rayleigh–Ritz 고유값 오차:** 같은 K를 모델 span에 투영해 구한 고유값의 평균 |λ_RR/λ − 1|, i=1..95와 i=1..10.
- **기준선:** 표면 Ours-Large를 부피에 **그대로** 적용(미세조정 없음).

|---|---|---|---|---|---|---|---|---|

| 처음부터 lr 5e-4 | 4.6e-3 | 1.1e-3 | 8.2e-3 | 2.0e-3 | 1.04e-2 | 5.3e-3 | 1.64e-2 | 6.3e-3 |
| 미세조정 lr 1e-4 | 3.0e-3 | **7.5e-4** | 4.6e-3 | 1.4e-3 | **4.7e-3** | **1.5e-3** | **6.2e-3** | **2.1e-3** |

- N=8192에서는 모든 고유값 오차가 약 절반으로 줄어듦(예: 미세조정 lr 3e-4, 같은 형상군 준균일 1.55%).
- Rayleigh–Ritz 고유값은 항상 위에서 근사하므로 오차는 모두 양의 편향임.
- 형상군별 span loss(같은 형상군 테스트, 미세조정 lr 3e-4): shell 1.8e-3 < superquadric 2.1e-3 < SH 공 2.3e-3 < 컵 2.4e-3 < 토러스 2.9e-3.

## 발견한 점

1. **미세조정이 처음부터 학습보다 확실히 나음.**
   - 같은 1시간에서 span loss가 같은 형상군 준균일 2048에서 4.6e-3 → 2.8–3.0e-3, C자 관에서 1.04e-2 → 4.7–4.9e-3.
   - 처음부터 학습은 초기 검증 손실이 46.5로 시작해 수렴에 시간이 더 걸리고 1시간 안에 수렴하지 못했음. 반면 미세조정은 첫 epoch부터 0.58–0.64.
   - 표면에서 부피로 가는 분포 차이가 크지만, 표면 가중치의 표현이 부피에도 상당 부분 옮겨짐.
2. **표면 가중치를 부피에 그대로 쓰면 부족함.** span loss 8.6e-3, 고유값 오차 6.3%로 미세조정의 약 3배. 부피용 재학습(미세조정)은 필요함.
3. **학습에 없는 형상군(C자 관)으로도 일반화되지만 오차가 약 1.6배 커짐.**
   - 미세조정 모델의 C자 관 span loss는 4.7e-3로, 같은 형상군(2.8e-3)보다 큼.
   - 그래도 처음부터 학습한 모델의 같은 형상군 성능과 비슷한 수준임.
   - 특히 저차 고유값 오차가 같은 형상군 0.6% → C자 관 2.4%로 커짐. 가늘고 긴 형상의 저차 모드(관을 따라 가는 모드)를 덜 정확하게 잡는 것으로 보임 [추측].
4. **해상도 전이가 동작함.** 2048점으로 학습했지만 8192점에서 span loss가 3–4배 낮아짐(2.8e-3 → 7.7e-4). 표면 NEO 논문의 zero-shot 해상도 전이와 같은 성질임.
5. **무작위 샘플은 준균일보다 약 1.5배 나쁨.** 입력 연산자(Delaunay-P1) 자체는 무작위에서도 수렴하므로, 모델이 불규칙 샘플을 더 어려워하는 것임. 학습 데이터의 절반을 무작위로 넣었지만 차이가 남음.
6. **미세조정 학습률 1e-4 vs 3e-4:** 같은 형상군에서는 3e-4가, C자 관에서는 1e-4가 조금 나음. 차이는 5–15%로 seed 하나로는 구분하기 어려운 수준임.
7. **참고: 표면 NEO와 비교.** 표면 NEO 논문의 ShapeNet 테스트 span loss는 3.35e-3(k=96). 부피 미세조정 모델은 같은 형상군 2048점에서 2.8e-3로 비슷한 수준임. 다만 데이터와 연산자가 달라 직접 비교는 아님.

## 정답 교차 확인 (세밀 사면체 FEM)

**방법** (`neo_vol_crosscheck.py`, `data_neo/crosscheck.csv`):
- 같은 형상군 테스트의 형상군별 형상 2개와 C자 관 2개에 대해, 같은 난수열을 재생해 샘플 점과 정규화 변환을 복원함(저장된 점과 일치 확인).
- 같은 입체의 세밀 사면체 메쉬를 만듦(h=0.04). 토러스·컵·shell·C자 관은 gmsh OCC, SH 공·superellipsoid는 조밀한 표면 메쉬에서 tetgen을 씀. 정점 수는 1.8만–13.6만 개.
- 세밀 메쉬의 P1 고유벡터를 점 위치로 보간하고, 파일럿 정답(Delaunay-P1)과 비교함.
  - 첫 32개(완전한 축퇴군 기준)의 span loss
  - 고유값 상대오차
- 48건 중 44건 성공. C자 관 두 번째 형상은 gmsh 합집합(fuse) 단계에서 빈 메쉬가 나와 제외함.

**Delaunay-P1 정답의 세밀 FEM 대비 span loss (형상군별 2개 평균)**

| 형상군 | 준균일 2048 | 준균일 8192 | 무작위 2048 | 무작위 8192 |
|---|---|---|---|---|
| SH 공 | 2.1e-3 | 1.7e-4 | 1.4e-2 | 5.7e-4 |
| superellipsoid | 2.3e-3 | 1.8e-4 | 1.6e-2 | 9.1e-4 |
| 토러스 | 3.0e-3 | 2.3e-4 | 1.8e-2 | 7.4e-4 |
| 컵 | 2.3e-3 | 1.6e-4 | 2.8e-2 | 6.8e-4 |
| shell | 1.9e-3 | 1.4e-4 | 1.1e-2 | 5.4e-4 |
| C자 관 (1개) | 3.0e-3 | 2.9e-4 | 8.2e-3 | 7.3e-4 |

- 고유값 평균 상대오차는 준균일 2048에서 0.8–1.9%, 8192에서 0.3–0.6%.

**해석:**
- **정답 생성은 올바름.** N=8192 준균일에서 모든 형상군이 span loss 1.4–2.9e-4로 세밀 FEM과 잘 맞고, N을 늘리면 줄어듦(REPORT_opcheck.md와 일치).
- **2048점 정답에는 이산화 오차가 포함됨:** 준균일 약 2–3e-3, **무작위 1–3e-2**. 무작위 2048점에서는 정답 자체가 세밀 FEM과 1–3% 어긋남.
- **파일럿 평가 수치를 읽는 법:**
  - 2048점에서 미세조정 모델의 정답 대비 span loss(준균일 2.8e-3, 무작위 4.3e-3)는 정답 자체의 이산화 오차와 같거나 작은 수준임. 이 해상도에서는 "연속체 참값에 얼마나 가까운가"가 모델보다 **2048점 연산자에 먼저 묶임**.
  - 8192점에서는 정답이 세밀 FEM과 1.4–9e-4로 가깝고 모델은 7.7e-4–1.3e-3임. 이 해상도에서는 **모델 쪽 오차가 더 큼**.
  - 본 학습에서 정답을 더 높은 해상도로 만들거나, 평가를 N ≥ 8k에서 하는 것이 모델 개선을 보기에 적절함.

## 환경 이슈와 해결

- **open3d import 순서:** `neo` 환경에서 저장소의 부피 학습 모듈(`g2pt.training.pretrain_tet`)을 불러오면 segfault가 났음.
  - 원인: **open3d를 h5py·torch·lightning보다 나중에 import하면 충돌**함(공유 라이브러리 로딩 순서 문제로 보임).
  - 저장소 코드는 수정하지 않고, 우리 스크립트 맨 앞에서 open3d를 먼저 import해서 해결함. 데이터로더 작업자는 spawn 방식이라 메인 모듈을 먼저 불러오므로 같은 순서가 유지됨.
- **tetgen 파이썬 래퍼:** `maxvolume=` 인자가 무시됨. 부피 제약은 switches 문자열(`pq1.5a…`)로만 적용됨. 교차 확인 첫 실행에서 SH 공·superellipsoid 기준해가 성겼던 원인이고, 수정 후 다시 돌림.
- **데이터 재생성:** 처음 생성을 시작한 뒤, 평가에 필요한 테스트 샘플의 연산자 K와 고유값을 저장하지 않는다는 점을 발견함. 30초 만에 해당 PID로 중단하고, 저장하도록 고쳐 다시 생성함.

## 한계와 다음 단계

- **seed 하나, 1시간 학습.** 미세조정 학습률 간 차이(5–15%)는 판단하기 어려움. 처음부터 학습은 수렴 전이므로 **"1시간 기준"의 비교**임.
- **정답의 해상도:** 2048점 정답은 세밀 FEM 대비 span loss가 준균일 2–3e-3, 무작위 1–3e-2임(교차 확인 절). 2048점 평가는 모델보다 연산자 이산화에 먼저 묶이므로, 본 학습의 평가는 N ≥ 8k 중심으로 하는 것을 권장함.
- **경계 여부 입력:** 결정 3에 따라 구조는 바꾸지 않았음. 표면 점 표시가 없는데도 동작하지만, C자 관의 저차 모드 오차가 큰 것을 보면 경계 정보 입력의 효과를 따로 시험할 가치가 있음 [추측].
- **권장:** 본 학습은 **표면 Large에서 미세조정**(lr 1e-4–3e-4)으로 진행함. 학습 시간을 늘리고, 데이터 형상군을 늘리며(특히 가늘고 긴 형상), 무작위 샘플 비중을 조정하는 것을 제안함.
