# robust_laplacian 편향 진단 — 결론

1. **질량은 원인이 아님.** 질량 총합은 면적과 0.4–2%만 다름(0.987–1.020, N=8000에서 ≤0.5%). M을 면적에 맞춰 스케일하면 편향이 오히려 커짐(정사각형 N=8000: −4.75% → −5.19%).
2. **원인은 강성(L)임.** 매끄러운 평면파 f의 에너지 fᵀLf / ∫|∇f|²는 0.95–0.96이고, 선형 함수 xᵀLx / 면적도 0.95로 같음. 반면 fᵀMf / ∫f²는 ≈0.995임. 따라서 −4.7% 편향은 거의 전부 L이 에너지를 약 5% 작게 잡아서 생김.
3. **n_neighbors로는 해결되지 않음.** nn=10: −17%, 20: −5.4%, 30: −4.7%, 50: −4.7%로 30 이상에서 평탄해짐. N=1000→8000에서도 줄지 않음.
4. **가장 간단한 보정은 선형 정밀도로 L을 스케일하는 것.** L' = c·L, c = sum(M) / mean(xᵀLx, yᵀLy) ≈ 1.045이고, 해석해 없이 클라우드만으로 계산됨. 보정 후 저차 편향은 N ≥ 4000에서 |편향| ≤ 0.55%로 줄어듦. 예외는 구멍 형상 N=1000으로 +3.1%인데, 구멍을 가로지르는 삼각형 때문에 sum(M)이 2% 부풀어서임.

표: [bias_tables.md](bias_tables.md). 재현: `python bias/bias_diagnostic.py` (spec_heat/에서 실행, 약 20초). 클라우드는 본 실험과 같은 시드의 균일 샘플 3개씩이며, 구멍 형상의 기준 고유값은 P2-FEM(h=0.01)으로 구함.
