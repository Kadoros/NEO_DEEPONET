- **NEO는 실제 형상에서 무너지지는 않지만, 뚜렷이 나빠짐.**
  - span loss 중앙값 1.2e-2 (quasi 8192) / 1.7e-2 (16384)이고, 고유값 오차 중앙값은 9–11%.

- **역반복 다듬기 1–2회로 거의 완전히 회복됨.**

  - 2회 후 span loss 1.5e-5 ~ 2.7e-3, 12/13개 형상이 1e-3 미만.
  - 주장 (5)의 "다듬기"가 실제 형상에서 동작함을 확인.
