# Stage 3 / E1: 기저 확인 (스칼라 기저 × 3성분 + 아핀 12개) — 2026-09-27

코드: `e1_basis.py`(본 실험), `e1_rot.py`(회전형 장 진단). 결과: `e1/e1_nu0.3_0.45_0.49.csv`, `e1/e1_rot.csv`.
연산자: 기본 P1 선형 탄성(2단계 Delaunay-P1 사면체), E = 1, 집중 질량. **locking 대응은 아직 넣지 않음** (다음 단계).

## 설정
- **형상 16개:** 8개 형상군 × 2개. sh_ball, superquadric, torus, cup, shell, elongated, multihole, c_tube.
  - 오목하거나 구멍 있는 형상: torus, cup, shell 공동, multihole, c_tube.
  - N = 8192 quasi. 2단계 데이터와 겹치지 않는 시드를 씀.
- **기저:** 모두 아핀 장 12개를 붙인 뒤 (M⊗I₃)-직교화하고, 탄성 K로 Rayleigh–Ritz를 함.

  | 이름 | 구성 | 차원 |
  |---|---|---|
  | `arpack128x3` | 스칼라 ARPACK 128 복제 | 396 |
  | `arpack256x3` | 스칼라 ARPACK 256 복제 | 780 |
  | **`neo256x3`** | 스칼라 부피 NEO(t4096) 256 + RR, 복제 | 780 |
  | `elastic256` | 정확한 탄성 고유벡터 262개 (기준용 최선 모드 기저) | 268 |

- **시험 1, 모드 포함도:** 정확한 탄성 고유벡터가 기저에 들어가는 정도를 span loss로 봄.
  - 대상: 강체 모드 6개, 비강체 모드 1~32번, 1~96번 (완전한 고유값 그룹 단위).
- **시험 2, 정적 해:** 자유 물체에 평형을 이룬 두 지점 하중을 줌.
  - 하중 두 가지: `pinch`(반지름 0.15 원판 균일 압력, 가장자리 날카로움)와 `smooth`(가우시안 압력, σ = 0.15).
  - 재료 두 가지: 균질, 덩어리 1~2개 (E = 5).
  - 전체 차수 P1 해와 기저 안의 Galerkin 해를 비교함. 지표는 상대 L2(M)와 에너지 오차.
- **진단 `sc`:** 기저에 그 하중의 균질 정적 해 벡터 1개(static correction)를 추가하고, 덩어리 재료에 적용함.
- **ν ∈ {0.3, 0.45, 0.49}:** 축소 모델 locking을 기록하는 용도임.

- 에너지 오차는 모든 기저에서 14~50%임. 하중 근처의 국소 응력 때문이며, 모드 기저로는 에너지 노름 1%가 원리적으로 어려움. **판정은 L2 기준으로 함.**
- **강체 모드:** 모든 형상, 모든 ν에서 강체 6개 모드가 정확히 포함됨 (span loss ≈ 1e-16). 전체 P1 연산자의 0 고유값도 정확히 6개임.
- **ν = 0.49 기본 P1의 스펙트럼:** 비물리적인 0 근처 모드가 없음.
  - λ₇ 평균은 0.80 / 0.76 / 0.82 (ν = 0.3 / 0.45 / 0.49)로, ν에 거의 무관함.
  - 선택적 절점 평균의 가짜 모드 확인은 이 연산자를 구현하는 다음 단계에서 같은 방식으로 함.

### 형상별 원인: 휘어지기 쉬운 형상에서 축소 모델이 뻣뻣해짐 (굽힘 locking)

| 형상군 | 최저 탄성 고유값 λ₇ | neo256x3 smooth 균질 오차 (ν 0.3) | elastic256 |
|---|---|---|---|
| c_tube (가는 C자 관) | 0.03–0.04 | 60–80% | ≤ 0.3% |
| torus | 0.22–0.32 | 25–33% | 0.6–1.8% |
| cup (얇은 벽) | 0.29–0.45 | 35–51% | 1.5–2.9% |
| elongated, multihole | 0.29–0.44 | 9–13% | 2.4–4.5% |
| sh_ball, superquadric, shell (덩어리형) | 1.3–1.9 | 6–10% | 6–9% |

- **덩어리형 형상:** 복제 기저가 정확한 탄성 모드 256개와 비슷한 수준임.
- **가늘거나 얇은 형상:** 정적 응답이 무른 굽힘 모드에 지배됨.
  - 굽힘 변형은 변형률이 거의 없는 "국소 회전" 장임.
  - 스칼라 저주파 함수를 성분별로 복제한 조합은 이 장을 변형률 에너지 상쇄 없이 근사하지 못함. 그래서 모델이 너무 뻣뻣해지고 변위를 과소추정함. 얇은 구조의 전단 locking과 같은 종류임.
  - 모드 1–96의 평균 span loss(6e-3)는 작아 보이지만, 가장 무른 모드의 작은 오차가 정적 해에서는 크게 증폭됨.

### 진단: 회전형 장 φ_k(x)·(e_c × (x − x̄)) 보강 (`e1_rot.py`, neo256x3 + 3·k_rot개)

| ν | k_rot | 차원 | span loss 1–96 | smooth 균질 | smooth 덩어리 | pinch 균질 |
|---|---|---|---|---|---|---|
| 0.3 | 0 | 780 | 6.4e-3 | 23.5% | 24.3% | 24.6% |
| 0.3 | 16 | 828 | 4.8e-3 | 9.0% | 9.5% | 10.7% |
| 0.3 | 32 | 876 | 2.8e-3 | 8.2% | 8.5% | 10.0% |
| 0.3 | 64 | 972 | **9.9e-4** | 7.5% | 7.8% | 9.3% |
| 0.49 | 0 | 780 | 5.0e-3 | 33.2% | 34.2% | 34.7% |
| 0.49 | 64 | 972 | 1.9e-3 | 27.2% | 27.9% | 28.8% |

- **ν = 0.3:** 가설이 확인됨. 휘어지는 형상의 오차가 크게 줄었음 (torus 29 → 9%, cup 43 → 10%, c_tube 70 → 24%). 가장 무른 모드의 span loss도 1e-3 → 약 2e-5로 줄었음.
  - k_rot = 64에서 모드 96개 span loss가 기준(≤ 1e-3)을 **만족함** (9.9e-4).
- **ν = 0.49:** 회전형 장은 거의 효과가 없음. 회전형 장 자체가 발산이 0이 아니라서(∇φ·(e×x) ≠ 0), 거의 비압축에서는 체적 벌점을 받기 때문임.
  - 비교 기준도 locking이 있는 기본 P1 해라는 점에 유의해야 함. 판단은 locking 대응 연산자를 넣은 뒤에 다시 해야 함.

## 판정 (기준: span loss ≤ 1e-3, 정적 해 L2 ≤ 1%)

| 기저 (ν = 0.3) | 모드 1–96 span loss | 정적 해 ≤ 1% | 판정 |
|---|---|---|---|
| neo256x3 (설계안 그대로) | 6.4e-3 | 23.5% | **불합격** (둘 다) |
| neo256x3 + 회전형 장 192개 | 9.9e-4 | 7.5% | 모드는 합격, 정적 해 불합격 |
| neo256x3 + 정적 보정 1개 | 6.4e-3 | 1.75% (덩어리) | 정적 해 근접, 모드 불합격 |
| elastic256 (정확한 탄성 모드) | 0 | 4.0% | 정적 해 **불합격** |

**결론**
1. **설계안 (a) 그대로(스칼라 NEO × 3 + 아핀)는 E1 불합격임.**
   - 덩어리형 형상은 정확한 탄성 모드 수준이지만, 가늘고 얇은 형상에서 굽힘 locking이 생김.
2. **정적 해 1% 기준은 정확한 탄성 모드 256개로도 불합격임 (4.0%).**
   - 국소 하중 응답은 모드 기저의 크기와 관계없이 하중에 맞춘 보강(정적 보정 등)이 있어야 1% 근처에 도달함.
   - 이 기준은 "모드 기저만으로"는 달성할 수 없는 기준임.
3. **보강 두 가지는 효과가 확인됨.**
   - 회전형 장: 굽힘 locking 해소, ν = 0.3
   - 정적 보정: 하중 국소부
   - 둘을 함께 쓰는 조합은 아직 시험하지 않았음.
4. **ν를 올리면 축소 모델 오차가 커짐 (복제 기저 23.5 → 33.2%).**
   - 반대로 정확한 탄성 모드는 오히려 좋아짐 (4.0 → 1.6%).
   - 복제 기저가 거의 발산 없는 장을 잘 담지 못한다는 기록임. 발산 없는 보강장 또는 탄성용 NEO(b)가 필요한 근거가 됨.
