## 0. 목적과 범위

- **3단계 질문:** 점 기반 사면체 분할(2단계 Delaunay-P1) 위에서, 비균질 영률 E(x)를 가진 선형 탄성 정적 문제의 변위를 **부분공간 Galerkin Â = Yᵀ K(E) Y** 로 정확하게 풀 수 있는가. 기저 Y는 NEO에서 옴.
- **3단계에서 하지 않는 것:** E(x) 추정(역문제)은 4단계, 표면 관측과 힘 미지는 5단계에서 다룸.
- **2단계에서 넘어오는 전제:**
  - 연산자 인터페이스 A4(`volop.Operator`: K, m, dof_dim, assemble(coef_e), grads, vol)를 d = 3으로 확장함.
  - 부피 NEO는 t4096으로 확정함 (추가 학습 없음).
  - B-3에서 NEO 256 기저가 스칼라 계수 복원에서 ARPACK 256과 거의 같은 품질임을 확인함 [확인].
  - B-4에서 복원된 세기의 편향이 기저 절단 오차와 관련 있음을 확인함 (피팅된 데이터 오차 < 정답 κ의 데이터 오차) [확인].

## 1. 문제 정의

- **지배 방정식:** 소변형 등방 선형 탄성 −∇·σ(u) = 0, σ = 2μ ε + λ tr(ε) I.
  - 라메 상수: μ = E/(2(1+ν)), λ = Eν/((1+ν)(1−2ν)).
  - E(x)는 비균질이고 ν는 균일함 (3단계).
- **이산화:** 2단계와 같은 Delaunay-P1 사면체 (SDF 제거 + 슬리버 제거).
  - 요소 강성은 K_e = vol_e B_eᵀ D(E_e, ν) B_e이고 12×12, 블록 3×3. B_e는 `p1_elements`의 기울기로 바로 만듦.
  - 질량은 집중 질량 M ⊗ I₃ (기저 직교화용).
- **자유도:** N = 8192이면 3N = 24,576. 평가는 2단계처럼 N ≥ 8192 중심.

## 2. 경계조건과 강체 모드

### 2.1 하중 경우 (도구 접촉)

| 이름 | 설정 | 용도 |
|---|---|---|
| **S1 ★** | 도구 패치 변위 지정 + 부착 영역 고정 | 기본. 조건수가 좋고 실제 장기(몸에 붙어 있음)와 비슷함 |
| S2 | 도구 패치 변위 지정 + 나머지 전부 자유 | 강체 모드 처리 검증 |
| S3 | 도구 패치에 견인력 지정(노이만) + 부착 영역 고정 | 5단계(힘 미지, 상대 강성) 대비 |

- **도구 패치:** 표면의 한 점을 중심으로 한 반지름 ρ ∈ [0.1, 0.2]의 원판 영역.
  - 기본 변위는 안쪽 법선 방향 압입 δ (형상 크기의 2~5%)임.
  - 패치의 3성분을 모두 지정함 (미끄러지지 않는 접촉).
  - 법선 성분만 지정하는 마찰 없는 접촉은 변형안으로 둠.
- **부착 영역:** 도구 반대편 표면 패치를 u = 0으로 고정함.
- S1·S2에서 도구 패치에 3성분을 지정하면, 한 직선 위에 있지 않은 점이 3개 이상이므로 **6개 강체 모드가 모두 제거됨**. 이 때문에 S2도 적정 문제(well-posed)임.

### 2.3 강체 모드
- **기저 보강 ★:** 기저에 **정확한 아핀 장 12개**를 붙인 뒤 M-직교화하고 Rayleigh–Ritz를 함.
  - 12개 = 평행이동 3 + 선형장 9 (회전 3 + 균일 변형률 6).
  - P1은 아핀 장을 정확히 표현하므로 강체 모드 6개가 부분공간에 정확히 들어감.
  - 복제한 스칼라 기저는 상수·선형 함수를 근사로만 포함하므로 보강이 필요함 [추측].
- **S2(자유):** 축소 강성 Â에 6차원 영공간이 생김. KKT 제약이 이를 제거하므로 따로 처리하지 않음.
- **검증:** Rayleigh–Ritz 고유값 1~6이 0에 가까운지(< 1e-8·λ₇) 확인함.

## 3. 기저: (a) 스칼라 NEO 3성분 복제 vs (b) 탄성용 NEO 재학습

### (a) 부피 NEO 스칼라 기저 복제 ★ (먼저 확인)
- **구성:**
  1. t4096의 256차원 출력 φ_k로 3·256 = 768개 벡터장 {φ_k e_i}를 만듦.
  2. 아핀 장 12개를 붙임 (중복 방향은 직교화 때 제거).
  3. (M ⊗ I₃)-직교화함.
  4. 탄성 강성 K(ν)로 Rayleigh–Ritz를 하고, 낮은 m_e개를 선택함.
- **장점:**
  - 재학습이 필요 없음.
  - **회전 등변성이 자동으로 성립함.** {φ_k e_i}가 펼치는 공간은 좌표계 회전에 불변임.
  - 2단계 NEO 품질(span loss 4.7e-4)을 그대로 씀.
  - Rayleigh–Ritz가 ν마다 다른 K에 맞춰 조정해 줌.
- **단점:**
  - 차원이 3배(768)임. Â 조립 메모리와 비용이 늘어남 (§8).
  - 탄성 저에너지 모드가 "스칼라 저주파 × 방향"으로 효율적으로 표현되지 않을 수 있음. 특히 ν → 0.5의 발산 없는 모드가 그럼 [추측].
- **먼저 할 실험 E1:**
  - 대상: 테스트 형상 10개 × ν ∈ {0.3, 0.45, 0.49} × 연산자 {P1, §4에서 고른 locking 대응}.
  - 지표 1: 정확한 탄성 고유벡터(ARPACK, 6 + 96개)가 부분공간에 들어가는 정도(span loss).
  - 지표 2: 실제로 더 중요한 지표로, **정적 하중 해(S1, 비균질 E 포함)의 투영 오차**와 축소 해 오차.
  - 비교할 기저 세 가지:
    - ① ARPACK 스칼라 256 복제 + 아핀. 복제 방식의 상한이며, NEO 오차와 방식 자체의 오차를 분리하기 위한 것.
    - ② NEO 256 복제 + 아핀.
    - ③ 정확한 탄성 고유벡터 m_e개 (최선의 모드 기저).
- **통과 기준:** ν = 0.45에서 둘 다 만족.
  - 탄성 모드 96개의 span loss ≤ 1e-3 (2단계와 같은 기준).
  - S1 정적 해의 상대 L2 오차 ≤ 1%.

### (b) 탄성 모드용 NEO 재학습 (E1 불합격 시에만)
- **구성:** 출력을 3·C 채널로 하고, 목표를 (K(ν), M⊗I₃)의 낮은 탄성 고유벡터(강체 6개 포함)로 함. ν는 입력 특징으로 주거나 ν마다 따로 학습함.
- **장점:**
  - 탄성 스펙트럼에 맞춘 압축 기저라, 256 정도로 768 복제와 같은 품질을 기대할 수 있음 [추측].
  - 발산 없는 모드를 직접 배울 수 있음.
- **단점:**
  - **회전 증강 때 목표 벡터 성분도 같이 회전시켜야 함.** g2pt의 회전 증강이 벡터 목표를 다루는지 코드 확인이 필요하고, 안 되면 수정해야 함 [추측].
  - 데이터 비용이 큼 (§8).
    - 탄성 고유분해는 스칼라의 약 5~15배 [추측].
    - 고유벡터 저장이 3배임. 형상 4200개 × 4샘플이면 약 79 GB로 **현재 디스크 여유(67 GB)를 넘음**.
  - ν 의존성과 locking 대응 방식에 따라 목표가 달라짐. 연산자를 확정한 뒤에만 가능함.
- **먼저 할 실험:** 2단계처럼 1시간 파일럿을 함.
  - 표면 Large 또는 t4096 가중치에서 시작하고, 출력층만 3배로 바꿈.
  - 데이터는 2048점, 형상 2100개 × 2샘플, float16 저장 (약 10 GB).

## 4. 비압축성 (locking)

### 4.1 확인 절차
- **순서:** ν = 0.3 → 0.45 → 0.49로 올리면서, 각 ν에서 아래 조합을 **참조 해와 비교**함.
  - 연산자 3종: P1, 선택적 절점 평균, 안정화 혼합 P1–P1 (후보는 §4.2)
  - 하중: S1과 S2
- **참조 해 두 가지:**
  1. **라메 해석해:** 내압을 받는 두꺼운 구 껍질. u_r = A r + B/r²이고 ν 전 범위에서 정확함. 형상은 2단계의 shell과 같은 종류임.
  2. **Taylor–Hood P2/P1 혼합 요소:** gmsh 세밀 메쉬에서 계산함. 일반 형상(sh_ball, cup, torus)용이고 scikit-fem(BSD-3, neo 환경에 설치)을 씀.
- **locking 판정 지표:**
  - 변위 상대 L2 오차
  - 압입 반력 (P1은 locking이면 과대)
  - 오차가 ν에 따라 커지는 정도 (0.3 → 0.49에서 오차 비 > 3이면 locking)
- **축소 모델 locking도 따로 확인함 (중요):** 전체 연산자가 locking 없이 풀려도, 기저가 발산 없는 장을 못 담으면 축소 해가 다시 뻣뻣해짐.
  - E1의 정적 해 오차를 ν별로 보고 판정함.

## 5. 비균질 E(x)

- **설정:** 2단계 B와 같은 "딱딱한 덩어리"를 씀.
  - 배경 E = 1, 구 1~3개, 반지름 0.15~0.25, 경계 폭 0.02, E_e = E(요소 중심).
  - 대비 E_hi/E_bg ∈ {2, **5**, 10}. 5는 2단계와 같은 값임.
  - ν는 균일함.
- **조립:**
  - 단위 E 요소 행렬 K̄_e(ν)를 미리 계산해 두면 K(E) = Σ_e E_e K̄_e (+ 절점 평균이면 Σ_n κ_n(E) K̄_vol,n)임.
  - 축소 행렬은 Â(E) = Σ_e E_e vol_e (B_e Y_e)ᵀ D̄(ν) (B_e Y_e)이고, 2단계의 Σ κ_e vol_e (∇Y_e)ᵀ(∇Y_e)와 **같은 구조**임.
  - (B_e Y_e)는 요소당 6 × m 텐서임.
- **메모리와 비용:** T ≈ 48k, m = 768 기준.
  - (B Y) 텐서는 fp32로 약 0.9 GB, fp64로 1.8 GB. **조립은 fp32, 풀이는 fp64 ★**.
  - Â 조립은 약 170 GFLOP로, RTX 3090 fp32에서 수십 ms [추측].
  - m ≤ 512면 fp64로도 가능함.
- **순문제 검증 지표:** 전체 차수 FEM(같은 분할, 같은 locking 대응) 대비 아래를 봄.
  - 변위 상대 L2 (부피, 표면)
  - 변형 에너지
  - 덩어리 주변의 국소 오차
- **4·5단계 대비 신호 크기:** ‖u(E) − u(E≡1)‖ / ‖u‖를 표면과 부피에서 따로, **덩어리 깊이별로** 기록함.
  - 표면 관측으로 덩어리가 얼마나 보이는지를 미리 측정하는 것이며, 2단계 위험 요소 9(표면만 관측)의 정량화임.

## 6. B-4 결과(256모드 판정)를 기저 차원에 반영하는 방법

- **2단계의 교훈 [확인]:**
  - 128모드에서 피팅된 데이터 오차가 정답 계수의 데이터 오차보다 5~10배 작았음. 기저 절단 때문에 모델이 틀린 계수를 선호한다는 뜻임.
  - 중간 결과: 256모드(ARPACK·NEO)에서 피팅 κ가 5에 더 가까워짐 (같은 형상 9개 중 8개). 다만 분할된 덩어리는 6 이상으로 과대추정됨.
  - 최종 판정은 `REPORT_main_and_coef.md`에 자동으로 추가됨.
- **결정 규칙:**
  1. **판정이 "예"(256이 세기 오차를 줄임)인 경우:** 3단계는 스칼라 256 복제(768)에서 시작하고, Rayleigh–Ritz 후 **m_e ≥ 512**를 유지함.
  2. **판정이 "아니오"인 경우:** 3·128 = 384 복제에서 시작함. 스칼라 문제에서 256의 이득이 없었다면 차원보다 다른 요인(평활화, 모델 구조)이 지배한다는 뜻임.
  3. 두 경우 모두 **E3 실험으로 최종 확정함.**
     - 비균질 S1 순문제에서 m_e ∈ {256, 384, 512, 768}의 축소 해 오차를 잼.
     - 가장 작은 m_e 중 두 조건을 만족하는 것을 고름: 오차 ≤ 덩어리 신호 크기(§5)의 1/10, 그리고 정답 E의 축소 모델 오차("oracle floor") ≤ 목표 노이즈 수준.
- **항상 기록할 진단:** 정답 계수로 계산한 축소 모델 오차(oracle floor)와 피팅된 오차를 같이 보고함. 피팅 오차 < oracle이면 기저 절단 편향 경고를 냄. B-4에서 배운 점임.
- **보강 후보 (불합격 시):** 하중별 정적 보정 모드(동차 K로 푼 u = K⁻¹f, 이른바 static correction)를 기저에 추가함.
  - 모드 절단 보강(modal truncation augmentation)으로 잘 알려진 방법이며 비용은 하중당 희소 풀이 1회임.
  - 이 경우 NEO의 역할이 줄어들므로 §7의 공정 비교에 포함해야 함.

## 7. 논문용 논리: NEO의 속도 이점이 필요한 상황을 실험으로 보이기

- **주장:** 수술 중에는 **매 프레임 형상이 바뀌고**(압입, 견인, 절제), 새로 재구성된 점군에는 이전 프레임과의 대응 관계가 불완전함. 매 프레임 탄성 기저를 다시 만들어야 하는데, 고유분해로는 실시간이 불가능하고 NEO로는 가능함.
- **확인된 비용 (스칼라, N=8192):**
  - ARPACK 256모드: 형상당 중앙값 27초 (2스레드, 서버 부하 있음) [확인]
  - NEO forward + Rayleigh–Ritz: 0.3초 [확인]
  - 탄성(3N 자유도)에서는 ARPACK이 수 분으로 늘어날 것으로 예상함 [추측]

**실험 P1: 규모 확장 곡선**
- N ∈ {4k, 8k, 16k, 32k, 65k}에서 프레임당 시간을 잼.
- 대상:
  - (i) Delaunay + ARPACK 탄성 모드
  - (ii) Delaunay + NEO + Rayleigh–Ritz
  - (iii) 전체 차수 희소 풀이 (하중 1개일 때)
  - (iv) 정적 보정 모드 기저
- 기대: NEO는 N에 거의 선형이고, ARPACK은 초선형임 [추측].

**실험 P2: 변형 시퀀스 ★ (핵심)**
- **데이터:** 장기 형상(sh_ball, cup)에 도구가 점점 압입하는 T = 100프레임 시퀀스.
  - 각 프레임을 새로 샘플링함 (N이 바뀜, 표면 노이즈 포함).
  - 중간 프레임에 일부 절제(위상 변화)를 넣어 대응 관계를 깨뜨림.
  - 덩어리는 조직과 함께 움직임.
- **파이프라인 비교:**
  - (A) 프레임마다 ARPACK 기저
  - (B) 프레임마다 NEO 기저
  - (C) 0번 프레임 기저를 최근접 대응으로 옮겨 재사용 (재계산 없음)
  - (D) 전체 차수 FEM 역문제
  - (E) 정적 보정 기저
- **지표:**
  - 프레임당 지연
  - 덩어리 위치와 대비 오차의 프레임별 추이
  - 시퀀스 전체 시간
- **기대하는 이야기:**
  - (C)는 변형과 위상 변화가 커질수록 무너짐.
  - (A)는 정확하지만 프레임당 수 분이 걸림.
  - (B)는 (A)에 가까운 정확도를 프레임당 1초 이하로 냄.
- **공정성 조건:**
  - (D)·(E)처럼 고유분해가 필요 없는 강한 기준선을 반드시 포함함. 심사에서 "고유분해 말고 선형 풀이면 되지 않느냐"는 질문이 나오기 때문임.
  - NEO의 이점이 "기저 품질 대비 비용"에서 나온다는 것을 보여야 함.
- **실행 시점:** 4단계 역문제 코드가 생긴 뒤. 3단계에서는 P1(순문제 시간 측정)까지만 가능함.
