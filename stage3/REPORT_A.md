### 판정
- **(c) 합격.**
  - 모드 1–96 span loss는 4e-8~7e-8로, 기준 1e-3보다 4자리 낮음.
  - 비율 기준 합격률은 93% / 96% / 98% (ν 0.3 / 0.45 / 0.49). 남은 불합격은 같은 차원의 정확한 모드에서도 생기는 해상도 한계임.
- **차원을 맞춘 비교:**
  - (c) ≈ 정확한 모드(같은 차원) + 정적 보정. 비율 평균 0.082 vs 0.093 (ν 0.3), 0.067 vs 0.054 (ν 0.49).
  - 즉 NEO 기반 보강 기저가 **같은 차원의 최선의 모드 기저와 동급**임.
  - 차원이 작은 정확한 모드 262개는 30–46% 합격으로, 차원이 결정적임.
- **회전형 장 제거 비교:**
  - 제거하면 합격률이 87 / 92 / 94%, 비율 평균이 약 20% 나빠짐.
  - 차이는 작지만 일관되고, 불합격은 얇은 cup과 shell에 몰림.
  - **결론:** 형상이나 방정식에 맞춘 손 보강 없이 **연산자 무관한 보강(정적 보정 + 연산자로 하는 역반복 다듬기)만으로 대부분 충분함.** 회전형 장은 얇은 형상에서 추가로 몇 %p를 올리는 선택적 보강임.
  - 단, 역반복은 해당 연산자 K를 쓰므로 "기저 생성(NEO)은 연산자 무관, 다듬기는 연산자 사용"이라는 의미임.
- **ν 증가에 따른 축소 모델 locking:**
  - (a)·(b)는 ν가 커질수록 나빠짐. (b) 합격률 85 → 79 → 53%.
  - (c)는 오히려 좋아짐 (93 → 96 → 98%). 역반복이 거의 발산 없는 저에너지 장을 담아 주기 때문임.

- 형상별 값은 `e1_v2_full_summary.txt`에 있음.
- **주의 1:** 정적 보정은 하중마다 전체 풀이 1회가 필요함. 새 하중마다는 이득이 없고, 하중 집합을 미리 정해 두는 경우(도구 패치 기저 등)에만 이득임.
- **주의 2:** 전체 풀이를 이번에 검증한 AMG-CG로 하면 1회 약 10–20초라 손익분기가 크게 늘어남.

## A4. 이론 그림 (`e1/a4_full.png`, 형상 16개, 점과 형상 이름만 표시)

- **Korn 상수 C_K:** 강체 여공간에서 계산한 에너지 동등성 상수 ∫∇u:∇u ≤ C_K ∫ε:ε.
  - 값 범위: shell 6.1–6.5, sh_ball 7.0–7.3, superquadric 9–12, cup 27–41, multihole 32–33, torus 47–72, elongated 48–49, c_tube 143–205.
- **Laplacian × 3 기저의 정적 해 오차는 C_K와 강한 순위 상관을 보임:** Spearman ρ = **0.74** (p = 0.001).
  - 두께 지표와는 ρ = −0.59 (p = 0.017).
  - C_K 6–12인 덩어리형 형상은 6–10%, C_K 27–205인 얇거나 가는 형상은 9–78%.
  - C_K가 비슷해도 cup이 elongated보다 나쁜 것은 두께 지표(0.16 vs 0.34)로 설명됨. 얇은 벽은 C_K만으로 다 설명되지 않음.
- **회전형 장을 넣으면** 상관이 약해짐 (ρ = 0.45, p = 0.08). C_K가 큰 형상의 오차가 가장 많이 줄어듦.
- **(c)의 남는 비율은 오히려 C_K와 음의 상관** (ρ = −0.83)임.
  - 보강 후에는 얇음이 아니라 덩어리 규모 해상도(형상 부피 대비 기저 차원)가 남는 오차를 정함.
- **결론:** "Korn 상수가 클수록(얇고 유연할수록) 라플라시안 기저가 나빠진다"가 16개 형상에서 확인됨. 보강 후에는 이 의존성이 사라짐.
