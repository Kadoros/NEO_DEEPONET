# 관문 실험 v2 설계 (실행 전 보고용) — 2026-09-28

v1의 교훈:
- 정답이 포인트 클라우드 연산자의 이산 해라서 학습 없는 Galerkin G가 거의 정확했음 (다듬은 기저로 처음 보는 형상 0.1% 이하).
- 학습 보정은 적은 데이터에서 학습 형상군에 맞춰져 처음 보는 형상에서 오차를 키웠음.
- Point-DeepONet은 학습 형상군에서도 15–27%라, 배수 기준이 의미가 없었음.

→ **v2는 학습이 반드시 필요한 과제**로 바꾸고, G를 기준선으로 넣고, 보정이 G보다 나빠지지 않는 구조를 쓰며, 판정 기준을 절대 오차 중심으로 바꿈.

## 1. 과제 (둘 다 제안; ★ B부터)

### ★ B. 숨은 열전도도 (공통 규칙, 모델에는 알려주지 않음)
- **규칙 (모든 형상에 동일):** 깊이 d(x)(표면까지 거리)의 함수 κ(x) = 1 + 3·σ((d(x) − 0.12) / 0.03).
  - 표면층(두께 약 0.1)은 κ ≈ 1이고, 속은 κ ≈ 4인 "단단한 심지" 구조임.
  - 깊이는 어떤 형상에서도 정의되므로 학습 형상군과 시험 형상에 같은 규칙이 적용됨.
  - 얇은 형상은 거의 전부 표면층이 됨. 이것도 규칙이 주는 자연스러운 이동임.
- **정답:** 같은 포인트 클라우드 연산자에 κ_e를 넣은 이산 해 (shift-invert Krylov, 형상당 수 초).
- **왜 학습이 필요한가:** κ ≡ 1을 가정하는 G는 규칙을 모르므로 체계적으로 틀림. 모델은 데이터에서 "깊이에 따라 느리게/빠르게 퍼진다"를 배워야 함.
- **우리 구조 (주장 4: 모드 결합은 국소 계수로 조립):**
  - κ̂_θ(x) = 1 + softplus(MLP[d(x), NEO 특징 F(x)]).
  - Â = Φᵀ K(κ̂) Φ (요소 텐서 조립, fp32), u = Φ exp(−tÂ) Φᵀ M u0.
  - 기저 Φ는 NEO 256 (원시 또는 다듬은 것), 선택적으로 + ε 보정 (아래 3절 방식).
  - 매개변수 약 5만 (+ ε 사용 시 약 24만).
- **Point-DeepONet:** v1과 같음 (데이터 로더만 수정, 저자 기본 설정, κ는 입력에 없음).

### A. 세밀 FEM 정답 (연산자와 정답 사이의 차이)
- **정답:** fTetWild 세밀 메쉬 P1 FEM(C-(b)와 같은 방식)을 클라우드로 보간한 해. κ = 1.
- **학습 대상:** 클라우드 연산자의 이산화 편향 (C-(b)에서 PC-discrete 대 세밀 FEM 0.3–1.1%).
  - 1단계에서 ε(r, r_p 입력)가 PC-discrete보다 낮은 오차를 낸 설정과 같은 종류임.
- **한계:** 학습할 차이가 작아서(1% 안팎) Point-DeepONet(15%+)과의 비교는 B보다 덜 선명함. 절대 오차 비교와 "학습 모델 < G" 항목이 핵심임.
- **추가 비용:** 학습용 합성 형상 160개에 세밀 메쉬와 세밀 FEM이 필요함. 합성 형상은 SDF → 마칭 큐브 표면 → fTetWild로 만들며, 형상당 약 2–4분 → CPU 8프로세스로 약 1–1.5시간.

## 2. 기준선
- **G-raw:** 학습 없는 Galerkin, 원시 NEO 256, κ ≡ 1.
- **G-ref:** 같은 것에 다듬은 NEO 256 (역반복 2회).
- **B 과제의 참고 상한 (학습 불필요):** 정답 κ를 넣은 G (G-oracle-κ). 기저 절단과 연산자 한계만 남는 값임.

## 3. 보정이 G보다 나빠지지 않는 구조 (원 논문 방식)
- **보정 출력층 0 초기화:** 학습 시작 시 모델 = G. 1단계 코드에 이미 있음 (`last_zero=True`).
- **단계별 손실 + stop-gradient:** L = ℓ(u_base) + ℓ(sg(u_base) + ε).
  - u_base: 과제 B에서는 κ̂로 조립한 Galerkin, A에서는 g_θ Galerkin.
  - ε 쪽 손실은 기저 부분으로 기울기를 보내지 않음. 기저 부분은 자기 손실로만 학습함.
- **검증 기반 선택:** 매 250스텝 검증 집합(학습 형상군)에서 G보다 나쁘면 그 체크포인트를 선택하지 않음 (G와 같은 0 보정 상태로 대체 가능).

## 4. 판정 기준 (수정)
1. **주 기준:** 처음 보는 형상(합성 OOD, 실제 형상 각각)에서의 절대 오차 순위와 값. 우리 vs Point-DeepONet vs G-raw / G-ref.
2. **배수 기준:** "기준 모델의 학습 형상군 오차가 5% 이하일 때만" 적용함. 우리 증가 ≤ 2배, Point-DeepONet ≥ 5배, 우리가 ≥ 3배 정확.
3. **별도 항목:** 우리 학습 모델이 G보다 나은가 (학습 형상군 / 합성 OOD / 실제 형상 각각).
4. **극단적으로 얇은 형상 (thingi472052, 두께 지표 0.07):** 포함한 값과 뺀 값을 모두 표기함.

## 5. 설정 (v1과 같음)
- 학습 형상 sh_ball·superquadric, N ∈ {50, 200} (형상, 초기조건) 쌍, 시드 {0, 7}.
- 시험: 학습 형상군 10개, 합성 OOD 20개 (torus, cup, c_tube, multihole), 실제 형상 13개.
