## 보충: 시험 시 기저만 다듬은 NEO로 교체 (재학습 없음, `gate_v2_refined.py`)

- 학습한 모델 4개(N50·N200 × 시드 2개)를 그대로 두고, 시험할 때만 기저를 NEO + 역반복 2회(+ RR)로 바꿈.
- κ̂ 네트워크의 입력은 깊이와 NEO 특징뿐이라 기저와 무관함. 따라서 κ̂는 두 경우 동일하고, 그림은 형상별 오차 비교(`gate/v2_refined_compare.png`)로 대신함.

| 모델 (κ̂ + ε) | N | 학습 형상군 원시 → 다듬은 | 합성 OOD 원시 → 다듬은 | 실제 형상 원시 → 다듬은 | 실제 (thingi472052 제외) |
|---|---|---|---|---|---|
| 우리 | 50 | 1.11% → 1.04% | 4.71% → 4.54% | 9.66% → **7.85%** | 9.17% → 7.34% |
| 우리 | 200 | 1.09% → 1.02% | 3.03% → 2.86% | 7.13% → **5.35%** | 6.83% → 4.94% |

- κ̂만 쓴 출력(ε 없음)도 같은 값임 (차이 < 0.01%p).
- **실제 형상에서 약 25% 줄어듦.** 원시 NEO 기저가 약한 형상에서 크게 줄고 (dragon 약 15% → 7%, cow·bunny 약 3.5% → 2.2%), 합성 OOD는 약 5%만 줄어듦.
- **남은 오차는 대부분 κ̂의 일반화 오차임.** 정답 κ를 다듬은 기저에 넣은 상한은 합성 OOD 0.44%, 실제 형상 0.33%임. → 다음 개선 대상은 κ̂ 네트워크 입력임.
