## 구성 (모두 NEO 기저)

**잔차와 사전해**
- Y = L-neo가 쓰는 NEO Ritz 벡터 96개(M-정규직교). 따라서 u0 = YYᵀMu0 + r로 정확히 분해됨.
- r = u0 − YYᵀMu0: NEO span 바깥 성분. 테스트 평균 ‖r‖_M/‖u0‖_M = 4.7%.
- r_p(t) = (M + tL)⁻¹ M r.
  - L은 전체 point-cloud 라플라시안 c·L_pc(nn=20, NEO Rayleigh–Ritz와 같은 연산자), M은 M_pc.
  - τ마다 희소 LU를 1회 수행함(형상당 8회, IC 4개 동시).

**ε_θ (새 입력)**
- trunk (점별 입력): [r(x), r_p(x,t), F(x), x, log t].
- branch (질량 가중 cross-attention): 점 토큰 (x, u0, r)을 받음.
  - 학습 가능한 query 8개가 전체 점에 attention을 걸고, softmax logit에 log mᵢ를 더함(면적 가중 구적과 같은 효과).
  - 결과를 flatten한 뒤 MLP로 보냄.

**비교 모델**

| 모델 | 구성 | 학습 |
|---|---|---|
| (a) L-neo | 1단계의 g_θ 가중치 그대로 | 없음(재평가만) |
| (b) L-neo + r_p | (a) + r_p(t) | 없음 |
| (c) L-neo + r_p + ε_θ | (b) + ε_θ(입력 r, r_p) | g_θ(L-neo에서 초기화) + ε_θ 공동 학습 |
| (d) L-neo + ε_θ(r) | (a) + ε_θ(입력 r만) | r_p는 합에도 입력에도 없음 |
| (d′) L-neo + ε_θ(r, r_p 입력) | (a) + ε_θ(입력 r, r_p) | 보조 실험. r_p를 입력으로만 주고 합에는 넣지 않음 |

(d)의 "r_p 없이"를 합과 입력 모두에서 빼는 것으로 해석했음. 해석이 갈릴 수 있어서 r_p를 입력에만 주는 (d′)도 같이 돌림.

**기준선**
- **PC-discrete:** 전체 point-cloud 연산자로 시간 방향을 정확히 푼 이산 해, `expm_multiply(−t M⁻¹ c·L_pc, u0)`. 이것이 새 비교 기준임.
- **Oracle-mesh96:** 메쉬 고유기저 96모드. 이제 모델이 96모드 밖으로 나갈 수 있으므로 상한이 아니고, 참고용으로만 둠.

## 발견한 점

1. **τ ≤ 0.03 평균 오차가 2.84%에서 0.19%로 15배 줄어듦 ((a) → (c)).**
   - 1단계 ε(branch에 NEO 계수만 입력)은 span 밖 성분을 전혀 복원하지 못했음.
   - 잔차 r과 사전해 r_p를 주자 그 한계가 사라짐.
   - (c)는 **PC-discrete(0.25%)보다도 낮음**(비율 0.76). PC-discrete의 오차는 point-cloud 연산자와 메쉬 연산자의 차이에서 오는데, 메쉬 정답으로 학습한 모델이 그 차이의 일부까지 보정한 것임.
2. **학습 없는 사전해 (b)는 초반에만 좋음.**
   - τ ≤ 0.003에서는 0.10–0.22%로 가장 좋음.
   - τ = 0.03에서는 1.22%로 (a)의 0.74%보다 나빠짐. 후진 Euler 한 스텝은 모드를 1/(1+λt)로 감쇠시키는데, span 바로 밖 모드처럼 λt ≳ 1인 모드에서는 이것이 e^{−λt}보다 훨씬 약하기 때문임(감쇠 부족).
   - (c)의 ε_θ가 이 부분을 고쳐서 τ = 0.03에서 0.26%가 됨.
3. **효과는 r_p를 입력으로 주는 데서 나옴.**
   - (d′)(r_p를 입력으로만 줌)와 (c)(입력 + 합)는 모든 τ에서 거의 같음(τ ≤ 0.03 평균 0.19%로 동일). 입력에 있으면 합에 더할지는 중요하지 않음.
   - r_p를 완전히 빼면 (d)는 0.26%(τ=0.0099에서 0.36%, 90퍼센타일 0.74%)로 PC-discrete 수준에 머묾. 네트워크가 r만 보고도 전파를 어느 정도 배우지만, 물리 사전해를 주면 τ ≈ 0.01 부근 오차가 약 35% 줄어듦.
4. **τ ≥ 0.1에서는 모든 학습 모델이 PC-discrete와 비슷함** (τ=0.1–0.96에서 비율 0.9–1.1).
   - τ = 3에서는 1.5배(0.12% vs 0.08%)임. 늦은 시간은 NEO 96모드 기저와 g_θ가 결정하고, 새 ε가 개선할 여지가 거의 없음.
   - 이 구간은 여전히 NEO 기저와 메쉬 연산자의 차이에 묶여 있음(1단계 발견 2).
5. **비용 ((c) 기준)**
   - 파라미터 237k. 학습 954 s(15k step, RTX 3090 1장).
   - 추론은 GPU forward 4.0 ms/형상(4 IC × 8 τ)에, r_p 준비 0.235 s/형상(CPU 희소 LU 8회)이 더해짐.
   - 참고로 PC-discrete(expm_multiply)는 10.5 s/형상임. 즉 전체 비용은 r_p 계산이 대부분을 차지함.
6. **DON-base를 수렴할 때까지 추가 학습함.**
   - 총 172k step, 3645 s. 마지막 20회 평가 동안 val 개선이 0.5% 미만이어서 멈춤. 최종 val 0.1008.
   - 테스트 평균은 17.4%(20k step) → **10.2%**로 좋아졌지만, 여전히 PC-discrete의 49배, (c)의 57배임.
   - τ ≤ 0.03 평균은 16.8%.
   - 연결 정보와 스펙트럼 구조 없이 점과 u0만 보는 일반 DeepONet은 수렴해도 이 문제에서 1% 수준에 가지 못함.
7. **Oracle은 더 이상 상한이 아님.** τ ≤ 0.03 평균 기준 Oracle-mesh96(2.78%) 대비 (b) 5배, (d) 11배, (c)·(d′) 15배 낮음.

## 과제에 명시되지 않아 스스로 정한 값

- **Y:** L-neo의 NEO Ritz 벡터 96개(256차원 span 전체가 아님). L-neo 항과 r이 정확히 분해되도록 하기 위함.
- **L:** 보정된 c·L_pc(nn=20). NEO Rayleigh–Ritz와 G-exact가 쓰는 것과 같은 연산자. M = M_pc.
- **PC-discrete:** 같은 보정 연산자에 expm_multiply(시간 방향 정확).
- **ε_θ 구조**
  - branch: 점별 임베딩 MLP 5→64→64, query 8개, 차원 64, head 4개, softmax logit에 log(mᵢ/Σm) 가산 → 512 → 256 → p=64.
  - trunk: [F̂(256), x, (log t + 3)/3]의 선형 임베딩(128)에 [r, r_p]의 선형 임베딩을 더함 → SiLU → 128 → SiLU → 64. 마지막 층은 0으로 초기화.
  - r과 r_p는 1/RMS_M(r)로 스케일(학습 셋 기준 79.3).
- **학습:** g_θ는 L-neo 가중치에서 시작해 ε_θ와 함께 학습. AdamW + OneCycle, lr 1e-3, 15k step, batch 8 형상, 250 step마다 val로 최선 가중치 선택. seed는 하나만 사용.
- **(d) 해석:** r_p를 합과 입력 양쪽에서 제거. 보조 실험 (d′)는 입력에만 넣음.
- **DON-base 수렴 기준**
  - 1단계 최선 가중치에서 재개. AdamW 3e-4 + ReduceLROnPlateau(factor 0.5, patience 4회).
  - 1000 step마다 val을 재고, 20회 연속 0.5%(상대) 이상 개선이 없으면 멈춤. 최대 400k step.

## 한계와 다음 단계

- **r_p 비용:** 추론 비용은 r_p(희소 LU)가 지배함. 비용을 더 줄이려면 한 번의 LU로 모든 t를 처리하는 방식이나, NEO 256 span의 나머지 160모드를 추가 기저로 쓰는 변형을 검토할 수 있음.
- **데이터:** 여전히 준균일 점(FPS)임. 무작위나 비균일 샘플링에서는 L_pc의 편향이 커져서 r_p와 PC-discrete도 영향을 받을 것임.
