# Stage 1 — 표면 열확산: 정확한 기저 vs NEO 기저로 만든 DeepONet 비교

## 재현

환경은 `neo`임. 캐시와 임시 파일은 `common.py`가 프로세스 안에서 `stage1/.cache`로 지정함.

```bash
python stage1/make_dataset.py                                   # CPU 24 프로세스, 약 10분
CUDA_VISIBLE_DEVICES=0 python stage1/neo_basis.py               # 약 2분
CUDA_VISIBLE_DEVICES=0 python stage1/train.py --shard exact &   # GPU 3개에 샤드 병렬 실행, 약 7분
CUDA_VISIBLE_DEVICES=1 python stage1/train.py --shard neo &
CUDA_VISIBLE_DEVICES=2 python stage1/train.py --shard don &
wait; python stage1/train.py --merge; python stage1/report.py
```

## 설정 요약

- **형상:** 600개 = 구면조화 섭동 구 / superquadric / 토러스 각 200개.
  - 정점 4000개인 준균일 메쉬(최소각 ≥ 14.7°, 평균 24.6°), 표면적 4π로 정규화.
  - 분할은 형상 단위, family별 층화로 160/20/20씩 → 480/60/60.
- **정답:** 메쉬 cotan(P1 강성) + lumped 질량으로 `expm_multiply(−t M⁻¹L, u0)`.
  - 한 형상에서 조밀 고유분해와 비교해 상대오차 4e-8로 일치함.
- **초기조건과 시간:** 형상당 초기조건 4개, 시간 8개(τ = t·λ₁ ∈ [1e-3, 3], 로그 균등).
- **평가:** 테스트 60개 형상 × 4 IC에서 ‖û − u‖_M / ‖u‖_M (M = 메쉬 lumped 질량).
- **Oracle-mesh96:** 메쉬 고유기저 96모드로 만든 Galerkin 해. 연결 정보를 쓰므로 모델이 아니라, "96모드로 가능한 최선"을 보여 주는 참고선임.

## 발견한 점

1. **τ ≤ 0.03에서 오차는 96모드 절단이 결정함.**
   - 모든 스펙트럼 모델이 Oracle의 1.01–1.03배(τ ≤ 0.01)임.
   - 정답 u(t) 중 NEO 기저 span 밖에 있는 성분은 τ별로 0.0440 / 0.0379 / 0.0242 / 0.0071이고, L-neo+ε 오차 0.0440 / 0.0379 / 0.0242 / 0.0074와 사실상 같음.
   - 즉 **ε_θ는 span 밖 성분을 전혀 복원하지 못함.** 과제 명세대로 ε의 branch 입력이 "u0를 NEO 기저에 투영한 계수"뿐이라서, u0 중 span 밖 부분에 대한 정보가 모델에 들어가지 않는 구조적 한계임.
   - 이 영역을 개선하려면 branch나 trunk에 u0의 점별 값, 또는 잔차 u0 − ΦΦᵀMu0를 넣어야 함.
2. **τ ≥ 0.1에서는 기저 불일치(pc 기저 vs 메쉬 연산자)가 오차를 결정함.**
   - G-exact 0.08–0.26%, G-neo 0.16–0.23%.
   - g_θ 학습으로 조금 줄어듦: τ=3에서 L-neo 0.16% → 0.13%, ε를 더하면 0.12%.
   - 전체 평균에서의 이득은 1% 미만임.
3. **g_θ는 편향 보정을 학습함 (L-exact-uncal).**
   - 보정 전 고유값(λ/c)을 넣은 G-exact-uncal은 τ=0.31에서 0.43%이고, L-exact-uncal은 0.19%임. 이는 보정된 L-exact와 같은 수치이고, 평균도 0.0161 → 0.0151로 줄어듦.
   - `fig_g_theta_uncal.png`에서 학습된 유효 감쇠율 ρ = −log g/(λt)가 형상별 c에 붙음: 구 c=1.0085 → ρ ≈ 1.0083–1.009, 토러스 c=1.0125 → 1.013–1.016.
   - 보정된 기저에서도 ρ는 메쉬/기저 고유값 비의 평균을 따라감: exact는 ρ ≈ 1.0005–1.003(pc λ가 메쉬보다 −0.15%), NEO는 ρ ≈ 0.999(NEO λ가 메쉬보다 +0.05%).
4. **NEO 기저는 이 데이터에서 ARPACK 기저와 동등함.**
   - pc 기저 대비 span loss 1.0e-4(최대 4.2e-4), 테스트 평균 오차 0.0151로 같음.
   - 기저 준비 시간: NEO 약 0.23 s(질량 0.10 s + forward 23 ms + Rayleigh–Ritz 0.11 s), ARPACK은 1.15 s.
5. **DON-base는 20k step에서 평균 17.4%(Oracle의 12.5배)였음.**
   - 이 시점에는 아직 수렴 전이었음.
   - 나중에 val이 정체될 때까지 추가 학습함(총 172k step, 3645 s, `results_eps/`). 결과는 평균 **10.2%**로, 여전히 스펙트럼 모델과 한 자릿수 차이임.
6. **이 데이터에서 pc 라플라시안(nn=20, N=4000)은 정확함.**
   - 점이 FPS 준균일이라 보정 후 메쉬 대비 −0.15%임(600개 평균, 최악 −0.67%).
   - 무작위 샘플에서 보였던 −5% 편향과 nn=20 붕괴는 이 설정에서는 나타나지 않음(neo_check/NEO_CHECK.md 7절).
   - 그래서 "편향 보정 학습" 효과를 보려면 uncal 실험처럼 편향을 인위적으로 넣어야 함.

## 과제에 명시되지 않아 스스로 정한 값

**형상**
- 구면조화 섭동: l = 2..6, a_lm ~ N(0,1)/l², 전체 섭동을 max|δ| ~ U[0.15, 0.4]로 스케일.
- superquadric: 반축 ~ U[0.6, 1.4], 지수 e1, e2 ~ U[0.5, 1.5].
- 토러스: R=1, r/R ~ U[0.2, 0.6].
- 모든 형상에 무작위 회전을 적용하고, 면적 중심으로 옮긴 뒤 표면적 4π로 정규화.

**메쉬**
- 정점은 정확히 4000개로, 조밀 후보점에서 farthest point sampling으로 뽑음.
  - 별 모양 형상: icosphere 6단계 방향을 반지름 함수로 사상해 후보점을 만듦.
  - 토러스: 면적 균일 무작위 6만 점을 후보로 씀.
- 삼각분할:
  - 별 모양 형상: 방향 벡터의 convex hull.
  - 토러스: conformal 좌표 (u, w)에서 주기 Delaunay.
- 모든 메쉬를 manifold와 Euler 표수로 검증함.

**연산자·정답**
- cotan = P1 강성행렬, lumped 질량 = 면적/3.
- λ₁ = 메쉬의 첫 번째 0이 아닌 고유값.
- t = τ/λ₁ (τ 8개는 geomspace(1e-3, 3, 8)).

**초기조건:** 가우시안 개수 ~ {1, 2, 3}, 중심 = 무작위 정점, σ ~ U[0.15, 0.5], 진폭 ~ U[0.5, 1.5].

**분할:** family별 층화 160/20/20 (seed 고정).

**기저**
- "ARPACK 96모드"는 상수 모드를 포함함.
- 보정 c = 2·sum(M)/Σ xᵢᵀLxᵢ를 형상마다 계산함.
- 기저 벡터 부호는 각 열에서 절댓값 최대 원소가 양수가 되도록 정규화함.

**NEO**
- 입력은 `normalize_pc` 좌표와 그 좌표의 pc 질량(nn=20, NEO 학습 설정)임.
- F = QR 이전의 원 출력(N × 256), F̂ = F / (질량 가중 RMS), z = 질량 가중 평균 F̂.
- Rayleigh–Ritz는 256차원 span에서 dense float64로 풀고, 가장 낮은 96개를 씀.

**계수·손실**
- 계수 ⟨u0, φ⟩는 pc 질량으로 계산함(모델은 연결 정보를 받지 않음).
- 평가와 학습 손실은 메쉬 질량으로 계산함(정답 쪽에서만 연결 정보를 씀).
- 학습 손실은 상대 L2 그 자체(제곱 아님)의 평균.

**g_θ**
- 형태: g = exp(−s·softplus(MLP)), s = λ_k t.
- 초기값은 ρ = 1(= plain Galerkin).
- 입력: log s / 3, log(λ_k/λ₁), z를 16차원으로 선형 투영한 값.
- 구조: MLP 64-64, SiLU.
- 상수 모드 g_0 = 1로 고정(질량 보존).
- λ₁은 해당 기저 자신의 값을 씀(메쉬 λ₁을 모르므로).

**ε_θ**
- branch: MLP 96-128-128-64, 입력은 NEO 계수 / √(4π).
- trunk: MLP [F̂(256), x, (log t + 3)/3] → 128-128-64, 마지막 층은 0으로 초기화.
- 학습된 L 모델의 g_θ에서 시작해 g_θ와 ε를 함께 학습함.

**DON-base**
- PointNet: 점별 [x, u0] → 64-128-256, 질량 가중 평균 풀링과 max 풀링 → 512-256-128.
- trunk: [x, log t] → 128×3 → 128. 잠재 차원 p = 128.

**학습**
- AdamW + OneCycle, batch = 8 형상(× 4 IC × 8 τ), grad clip 1.
- step 수와 lr: L 3000 step(lr 3e-3), L+ε 10000(1e-3), DON 20000(1e-3).
- 250 step마다 val을 재고 최선 가중치를 사용. 학습 seed는 하나만 사용.

**Oracle-mesh96 참고선**과 **L/G-exact-uncal**(λ/c 사용)은 추가 요청이나 해석을 위해 넣은 것임.

## 한계와 다음 단계

- **ε 설계:** 명세의 입력만으로는 절단 오차를 줄일 수 없음(1번). u0의 점별 값이나 span 밖 잔차를 입력에 추가하는 변형을 시험할 가치가 있음.
- **DON-base:** 수렴할 때까지 추가 학습한 결과(10.2%)로도 결론은 같음.
- **샘플링:** 이 데이터는 준균일 점이라 pc 라플라시안 편향이 작음. 무작위나 비균일 샘플링 데이터에서는 G-exact와 L-exact의 차이, NEO의 이점이 달라질 수 있음.
