# P0 — 1단계 한계 두 가지 재평가 (재학습 없음)

## 무엇을 했나

1단계 모델을 **다시 학습하지 않고** 새 점 집합에 그대로 적용함.

**점 집합 (각 N=4000):**

| 세트 | 형상 | 점 |
|---|---|---|
| T0 | 1단계 테스트 형상 60개 | FPS 메쉬 정점 (1단계와 같음) — 기준 |
| T1 | 같은 형상 | 표면에서 균일 무작위 샘플 |
| T2 | 같은 형상 | 비균일 샘플 (형상마다 임의 방향의 반공간에서 밀도 5배) |
| T3 | **학습에 없는 형상군** "dumbbell" (두 공의 매끄러운 합집합) 60개 | FPS 메쉬 정점 |

**정답 (모든 세트 공통): 세밀 메쉬.**
- 4k 메쉬를 두 번 1→4 분할하고 새 정점을 참 표면으로 사영함(약 64k 정점).
- cotan + lumped 질량, Crank–Nicolson(Rannacher 시작)으로 풀고, 점 위치로 무게중심 보간함.
- 검증 결과 [확인]:
  - 형상 재현 오차 6e-8
  - CN vs expm_multiply 오차 ≤ 1.5e-6
  - 보간 코드: 행 합 1, 가중치 ≥ 0

**평가 가중치:** 세밀 메쉬의 질량을 가장 가까운 점에 모은 값(제한 Voronoi 면적). 정답 쪽에서만 사용함.

**모델 입력:** 점에서만 다시 계산함. pc 라플라시안(nn=20) + 보정 c, NEO 기저 + Rayleigh–Ritz, r, r_p, PC-discrete.

**비교 DON:** 이번 탐색의 최적 DON-base-matched(정규화, p=256, lr 1e-3, 237,838 파라미터)와 기존 DON(정규화 없음)을 함께 평가함.

재현:

```bash
python stage1/p0_make.py
CUDA_VISIBLE_DEVICES=<gpu> python stage1/p0_eval.py
```

결과: `results_p0/tables.md`, `errors.csv`, `t0_fine_vs_4k.csv`, `fig_p0_error_vs_tau.png`

**판정: τ ≤ 0.3에서 해석이 유지되고, 오히려 강해짐. τ ≥ 1에서는 원래부터 성립하지 않음.**

- **해석이 유지되는 근거:**
  1. 세밀 정답에 대해서도 (c)는 PC-discrete보다 정확함. τ ≤ 0.03 평균 비율이 **0.63**으로, 4k 정답 기준(0.75)보다 더 낮음. PC-discrete는 정답을 세밀하게 바꾸자 오차가 커졌지만(0.00252 → 0.00273), (c)는 줄었음(0.00192 → 0.00180).
  2. τ ≤ 0.003에서 (c)의 세밀 정답 대비 오차(0.00076, 0.00136)는 **1단계 4k 정답 자체가 세밀 정답과 벌어진 정도**(0.00076, 0.00121)와 같은 수준임. (c)는 학습 정답(4k 메쉬)의 이산화 오차 한계에 닿아 있음.
- **예상했던 우려는 해당하지 않음:** "(c)가 4k 메쉬의 이산화 오차를 외워서 입력 연산자를 이긴 것처럼 보였다"는 우려는 데이터로 뒷받침되지 않음. 그런 경우라면 세밀 정답에서 비율이 1에 가까워지거나 넘어야 하는데, 반대로 낮아졌음.
- **한정할 점:** τ ≥ 1에서는 (c)가 PC-discrete보다 나쁨(1.1–1.5배). 늦은 시간은 NEO 96모드 기저와 g_θ가 결정하는 구간으로, 1단계에서 이미 관찰된 것과 같음. 따라서 정확한 표현은 **"τ ≤ 0.3에서 (c)가 입력 연산자보다 정확하다"**임.

## 3. 발견한 점

1. **한계 ① "같은 형상군 테스트"는 해소됨.**
   - 학습에 없는 dumbbell 형상군(T3)에서 (c)는 τ ≤ 0.03 기준 0.0020, 전체 0.0020으로 T0(0.0018)와 거의 같음.
   - 형상 특징을 쓰는 부분(NEO 기저, F, z)이 새 형상군에서도 무너지지 않음.
2. **한계 ② "준균일 샘플링"은 실제 약점이고, 원인은 입력 연산자임.**
   - (c)의 τ ≤ 0.03 오차: T1(무작위) 0.0082로 T0의 약 4.5배, T2(비균일) 0.0126으로 약 7배.
   - 그런데 **PC-discrete 자체가 T1에서 4.3배, T2에서 6배 나빠짐.** pc 질량이 면적보다 3–5.5% 작고(nn=20, 무작위 점), 곡면 보정 c가 1.045로 커짐. 1단계와 neo_check에서 본 무작위 샘플 편향이 그대로 나타난 것임.
   - 모델은 이 연산자로 만든 기저와 r_p를 입력으로 받으므로 편향을 물려받음. 그래도 모든 세트에서 PC-discrete보다는 나음(T1 0.0082 vs 0.0117, T2 0.0126 vs 0.0164).
   - 늦은 시간(τ ≥ 0.1)은 모든 모델이 PC-discrete 수준(1.2–3%)에 묶임. 입력 연산자의 오차가 그대로 전파되는 구간임.
3. **무작위·비균일 샘플에서는 (d)가 (c)보다 조금 나음** (T1 0.0074 vs 0.0082, T2 0.0121 vs 0.0126).
   - (d)는 편향된 연산자로 만든 r_p를 쓰지 않음. 연산자가 나빠지면 물리 사전해의 이점이 줄어듦.
   - 준균일(T0, T3)에서는 (c)가 여전히 가장 좋음.
4. **G-neo가 G-exact보다 무작위·비균일 샘플에 더 강건함** (T1 전체 0.0237 vs 0.0258, T2 0.0327 vs 0.0353). NEO 기저가 불규칙 샘플의 pc 연산자 고유벡터보다 덜 흔들림.
5. **DON(최적 포함)은 샘플링 방식에 거의 무관하게 약 10%에 머묾.** 오차가 큰 대신 연산자 편향의 영향은 받지 않음. 공정성 보완(정규화 + 파라미터 맞춤 + 탐색)으로 0.102 → 0.098.

## 4. 결론과 다음 단계에 주는 함의

- **1단계의 핵심 주장 두 가지는 유지됨.**
  - 잔차 입력 ε가 96모드 절단을 해결함.
  - (c)가 τ ≤ 0.3에서 입력 연산자보다 정확함(세밀 정답 기준으로 더 강하게 성립).
  - 새 형상군으로도 일반화됨.
- **무작위·비균일 점에서의 성능은 point-cloud 연산자 품질이 결정함.** 모델 쪽을 고쳐서는 한계가 있음. 이는 2단계 설계(DESIGN.md 결정 1, 2)와 같은 결론임: **연산자 검증과 합격 기준(무작위 샘플에서 N 증가 시 수렴)이 가장 먼저임.**
- 곡면에서도 같은 개선을 시험할 가치가 있음 [추측]: nn=30으로 바꾸거나 Delaunay 계열 연산자를 쓰고, 무작위 샘플을 학습 데이터에 포함.

## 한계

- **무작위·비균일 샘플에서는 입력 연산자 편향이 오차 하한을 결정함.**
  - PC-discrete 자체가 T1에서 4.3배, T2에서 6배 나빠지고, pc 질량이 면적보다 3–5.5% 작음.
  - 모델은 이 연산자로 만든 기저와 r_p를 입력으로 받으므로 그 아래로 내려가기 어려움.
- **해결 후보:**
  - (i) 더 정확한 연산자: 2단계의 Delaunay-P1 계열. 곡면에도 같은 방향 적용을 검토.
  - (ii) 다양한 샘플링(무작위·비균일)을 학습 데이터에 포함.
