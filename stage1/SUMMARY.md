# Stage 1 요약 — 표면 열확산에서 NEO 기저 기반 신경 연산자

## 목표

연결 정보가 없는 포인트 클라우드(곡면)에서 열방정식을 빠르고 정확하게 푸는 신경 연산자를 만드는 것.

비교 대상:
- ARPACK 고유기저 vs NEO(신경망으로 예측한 고유공간) 기저
- 학습 없는 Galerkin vs 학습된 스펙트럼 보정(g_θ) vs 보정항(ε_θ) vs 일반 DeepONet

## 설정

- **형상:** 절차적으로 만든 닫힌 곡면 600개. 구면조화 섭동 구, superquadric, 토러스를 각 200개씩.
  - 정점 4000개의 준균일 메쉬(FPS)이고, 모델에는 점만 줌.
  - 형상 단위로 480/60/60 분할(family별 층화).
- **정답:** 메쉬 cotan + lumped 질량으로 푼 노이만 열방정식, `expm_multiply`.
- **입력과 시간:** 초기조건은 가우시안 1–3개의 합으로 형상당 4개. 시간은 τ = t·λ₁ ∈ [1e-3, 3]에서 8개.
- **지표:** 메쉬 질량 가중 상대 L2 오차. 테스트 60개 형상 × 4 IC.
- **기저:** robust point-cloud 라플라시안(nn=20)에 곡면 보정 c = 2·ΣM/ΣxᵢᵀLxᵢ 적용. NEO는 공개 가중치(Ours-Large)에 같은 L로 Rayleigh–Ritz해 96모드를 얻음.

## 주요 결과 (테스트 평균 상대오차)

| 모델 | τ ≤ 0.03 평균 | 전체 평균 | 비고 |
|---|---|---|---|
| Oracle-mesh96 (메쉬 고유기저 96모드, 참고) | 2.78% | 1.39% | 연결 정보 사용 |
| PC-discrete (전체 pc 연산자, 시간 정확) | 0.25% | 0.21% | 2단계의 기준선 |
| G-exact / G-neo (Galerkin 96모드) | 2.84% | 1.51% | 학습 없음 |
| L-neo (g_θ 학습) / L-neo + ε(1단계 입력) | 2.84% | 1.51% / 1.50% | 96모드 절단에 묶임 |
| **L-neo + r_p + ε(잔차 입력)** | **0.19%** | **0.18%** | 파라미터 237k, 추론 4 ms + r_p 0.24 s |
| DON-base (수렴, 172k step) | 16.8% | 10.2% | 일반 DeepONet |

## 발견한 점

1. **NEO 기저는 ARPACK 기저와 동등함.** span loss 1e-4, 오차가 같음. 기저 준비 시간은 0.23 s vs 1.15 s.
2. **96모드 Galerkin의 오차는 작은 τ에서 절단이 지배함.** span 밖 성분에 대한 정보가 없는 한, 학습(g_θ, 1단계 ε)으로는 고칠 수 없음. 오차가 span 밖 잔차 크기와 일치함을 확인함.
3. **잔차 r = u0 − YYᵀMu0와 물리 사전해 r_p = (M + tL)⁻¹Mr을 ε 입력으로 주면 해결됨.**
   - τ ≤ 0.03 평균 오차가 15배 줄어듦.
   - 전체 pc 연산자로 푼 해(PC-discrete)보다도 낮음. 메쉬 정답으로 학습해서 연산자 차이 일부를 보정한 것임.
   - 효과는 r_p를 입력으로 주는 데서 나오고, 합에 더하는 것은 중요하지 않음.
4. **g_θ는 고유값 편향을 학습함.** 보정 전 고유값을 주면 학습된 감쇠율이 형상별 c에 정확히 붙음.
5. **point-cloud 라플라시안(robust_laplacian) 관련:**
   - 무작위 샘플에서는 저차 고유값이 −5% 편향됨(강성 원인이며 c로 약 −1%까지 보정됨).
   - nn=20에서 N ≥ 8000이면 무너짐.
   - 준균일 샘플이나 nn ≥ 30이면 안정적임.
6. **일반 DeepONet은 수렴해도 10%대**로, 스펙트럼 구조를 쓰는 모델보다 50배 이상 나쁨.

## 한계

- **같은 형상군 테스트:** 학습과 테스트가 같은 세 family에서 나옴. 처음 보는 형상군에 대한 일반화는 검증하지 않음.
- **준균일 샘플링:** 점이 FPS 메쉬 정점이라 pc 라플라시안 편향이 거의 없음(−0.15%). 무작위나 비균일 샘플에서는 기저, r_p, PC-discrete가 모두 나빠질 수 있음.
- **문제 범위:** 곡면, 균일 열전도도, 노이만 경계만 다룸. 추론 비용은 r_p(CPU 희소 LU)가 지배함. 학습 seed는 하나만 사용.

## 다음 단계 제안

1. 무작위·비균일 샘플과 학습에 없는 형상군으로 1단계를 재평가함. 비용이 낮고, 한계 두 가지를 바로 확인할 수 있음.
2. r_p를 NEO 부분공간 deflated PCG로 가속함.
3. 부피(내부 + 표면 점)로 확장하고, 불균일 계수와 Pennes 방정식을 다룸. 설계는 `stage2/DESIGN.md`에 있음.
